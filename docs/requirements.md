## 1 用户目标

管理员管理组织用户、角色和功能权限，配置可用模型、锁定 DSH 模板及资源规格；获授权用户点击“创建并运行”，自动获得独立、持久化、可安全进入的 DSH 工作空间。用户进入后即可对话并执行批准的文件工具，无需 SSH、手动安装依赖、编辑配置或再次填写模型 Key。

初始版本发布定位为受控内部试点，核心完成条件为真实创建、实际使用、安全访问和原数据恢复。

## 2 范围与前提

| 项目 | 初始版本定义 |
| --- | --- |
| 组织 | 一个部署对应一个组织，无组织切换和跨企业租户 |
| 身份 | 平台 Go 内置 OIDC Provider、Authorization Code + PKCE、BFF 服务端会话；内置管理员/成员及自定义角色，实例绑定真实 Owner，不能匿名开放管理面 |
| 后端 | Docker 单机 |
| 技术栈 | 后端 Go + Redis + PostgreSQL；前端 React/TypeScript 配套方案见前端技术选型 |
| 编排 | Go 后端内嵌 Workspace、版本化 Terraform 模板与构建模块，由 Worker 执行本机 Docker 资源编排 |
| 模板 | 一个经过真实验证的 DSH 版本与镜像 digest |
| 规格 | CPU 可选 1/2/4/8/16 核，内存可选 2/4/8/16/32/64 GiB，存储默认 10 GiB，管理员以数字设置 1–100 GiB 整数，实际组合来自批准目录 |
| 模型 | 支持DeepSeek直连及平台模型网关外部模型；平台数据库统一管理提供商、模型与别名。组织共享连接可选，运行默认值可独立初始化；每个用户可建立多个私有模型提供商账号并分别设置账号默认模型；用户在平台填写个人提供商Key，无需另进平台模型网关管理 |
| 用户 | 管理员新增/查询/编辑/启停用/删除组织用户、分配角色及资源配额；可信内部成员只访问本人实例 |
| 授权 | 单用户一个组织角色；内置角色与自定义角色绑定固定权限目录，服务端逐请求和事务内校验 |
| 数据 | 独立 Docker 卷，工作目录及已验证的 DSH 配置/会话目录持久化 |
| 访问 | 受控入口与 DSH 原生认证，浏览器不暴露启动 Token |
| 运维 | 单机安装、诊断、基础日志与备份恢复步骤 |

受控 Terraform CLI/Provider、模型账户、Docker 主机、可用镜像、HTTPS 域名和持久化/备份路径是运行依赖。平台部署初始化与用户“一键创建”分别验收，不能把一键创建宣传为基础设施自动安装。

前后端选型及职责见 [后端技术架构](backend.md#2-技术选型) 和 [前端技术架构](frontend.md#61-技术选型)。

首版采用 OIDC+BFF，首次管理员通过受控账号导入初始化，并绑定独立 Workspace Owner；后续用户与角色通过管理员页面及受控 API 管理。登录凭据由平台数据库保存 bcrypt 散列，签名私钥通过受控只读文件配置，平台以不可变 issuer+subject 绑定身份，未登记主体禁止访问，不能信任任意身份头。用户与授权规则见第 6.4～6.6 节，权限矩阵和会话协议见 [安全设计](security.md)，已有配置数值见 [配置基线](deployment.md#8-配置与业务规则基线)。

## 4 不在范围

多组织、集群后端、高可用、动态模板/规格治理、审计导出、自动轮换/休眠、精细用量/预算、自助备份恢复、协作/批量/审批、Git集成、DSH内MCP自动调用、完整SkillHub市场搜索/排行、多源目录聚合、Skill发布、私有SkillHub账号及跨实例组织级Skill分发不属于初始版本。工作台连接器另列为REQ-23扩展需求，首阶段为远程连接、工具发现与手动调用。

模型目录、个人Key、原生协议适配和受限运行密钥均由本平台实现与管理；不引入独立模型数据库或第三方代理运行组件。多入口调度、复杂用量结算和多模态不在初始范围。

资源限制、基础授权、TLS、审计和运维恢复仍必须实现。到期永久回收由受信运维执行；Owner可二次确认后申请提前释放本人已删除工作空间的数据，后台核实物理回收后才返还额度，规则见第6.12.6节。

## 5 核心流程

### 5.1 管理员初始化与创建

预检并批准运行模板、规格和资源上限，初始化运行默认值与模型账号。成员选择资源及本人模型账号提交创建，平台校验额度、运行状态后提供安全入口。首次验收通过后开放内部试点；详细规则见第6节，状态展示见第7.6节。

### 5.2 模型配置与应用

用户在“模型提供商”管理账号和默认模型；新建工作空间绑定所选账号的有效默认值，Owner可显式更新已有实例。同步、校验、版本和失败恢复见第6.7、6.8节。

### 5.3 用户与授权

管理员创建用户、分配角色和资源额度；角色或用户状态变化后，旧会话按新授权失效。身份、权限和撤销规则见第6.4～6.6、6.9、6.11节。

### 5.4 工作空间与数据

停止或软删除保留数据并按规则计额；启动复用原卷。备份、恢复和回收遵循资产归属、保留及运维确认规则，见第6.12节。

### 5.5 个人技能包

用户在 Portal 的“技能包”维护个人库，创建或导入后编辑内容并导出文件。公开链接先获取预览，再确认保存；来源更新由用户手动检查，替换前保留上一版。下载 Markdown 或 ZIP 后可自行导入 DSH；不修改容器。详见第 6.14 节。

### 5.6 记忆与知识库（分阶段交付）

用户在工作台连接已批准的外部开源服务，管理本人记忆与文档库。内容可按个人或工作空间范围整理，检索并查看授权原文；可关联本人工作空间或导入迁移包复用内容。检索结果展示记忆来源或文档引用；外部服务故障明确提示，不伪装成已完成检索。详见第 6.15～6.16 节。

### 5.7 连接器（MCP）

用户在工作台“连接器”添加本人的MCP服务地址及凭据，或跳转厂商页面完成OAuth授权，验证兼容性后查看工具目录，选择允许使用的工具。企查查提供OAuth和API Key两种接入方式，以同一连接展示五类服务及各自可用状态。试调用时填写参数并确认发送范围，在页面查看执行结果；可停用连接、重新同步目录、查看连接信息及调用记录。详见第6.17节；这些是需求流程，当前实现和验收状态见测试文档。

## 6 配置与状态规则

模板、规格、DSH 版本、镜像 digest、模型配置版本和凭据引用形成实例快照。保存后的明文 Key 不读回、不进普通创建请求/日志；模型 Key 仅注入必要组件，平台数据库/OIDC/控制面凭据不得进入用户容器。

实例保留 desired_state 与 observed_state，应用、存储、访问、模型健康独立判断。正常进入要求运行、应用/存储/访问健康和合法身份；模型异常时允许经授权进入诊断，但必须显式显示降级，不能宣称可执行 Agent 任务。

初始版本不承诺模型 Key 对有 Shell 权限的用户绝对不可见；需要隐藏 Key 时采用验证过的凭据代理。手动撤销必须明确直接注入与上游 Key 吊销的边界，不能把 UI 删除记录当作凭据已失效。

### 6.1 默认配置与凭据

一个固定组织、一套批准模板/规格、可选的组织共享默认模型，以及每用户多个私有模型提供商账号，每个账号设置一个默认模型。Portal 创建须明确选择本人模型提供商账号，自动绑定该账号默认模型当前版本；账号或默认模型失效时返回错误，不静默回退。服务端保留未显式指定时个人/组织默认的兼容解析能力，Portal 不使用此回退。默认变更只影响后续新建或显式更新；已有实例通过“更新模型提供商”选择本人账号后应用其默认模型，重启影响须提示。私有账号与模型规则见第 6.8 节。

模型校验验证指定协议、凭据、模型与必要工具能力，使用合成内容、有界超时/重试/输出，并告知费用。总超时 30 秒、最多 2 次上游请求、单次输出 128 tokens、结果 5 分钟有效；持久每日次数与流量限制见配置基线。健康过期按 UNKNOWN。

运行默认值可在没有任何组织模型或模型提供商账号时初始化。具备 `defaults:write` 及其读取依赖权限的管理员或自定义角色，在平台配置抽屉选择 CPU/内存组合，以数字设置存储容量、每用户默认实例上限与数据保留期限；运行模板由后台使用已批准版本，弹窗不展示模板字段。CPU 支持 1/2/4/8/16 核，内存 2/4/8/16/32/64 GiB，存储支持 1–100 GiB 整数、默认 10 GiB，实际组合须存在于批准目录。每用户实例上限为正整数，不得超过组织总上限，也不得低于继承默认额度用户的现有占用；单独分配额度的用户不受默认上限变更影响。保留期限为 1–365 天，默认 7 天；软删除确认时固化到资产，现有更长期限不缩短，永久回收仍另有软删除后至少 7 天及法律保留的安全门槛。

初始化提交版本 0，修改提交读取到的版本；并发冲突须重新读取并确认，不覆盖其他修改。配置、默认额度及审计同事务提交，任一失败全部回滚。运行资源变更用于后续创建，不改动已有实例冻结规格或模型。用户创建仍须选择本人有效模型提供商账号，无模型不允许运行；不能以运行默认值已初始化代替模型能力校验。

### 6.2 幂等与资源口径

相同主体/组织/动作/目标下同 Key 同参数重放原操作与首次快照；默认项变化不产生新实例。同 Key 不同参数拒绝。请求规范化、16～128 字符 Key、终态后至少 7 天有效期和冲突码已在配置及 API 固定。

每实例单个 ACCEPTED/RUNNING/UNCERTAIN 操作。异常实例在无活跃操作、无冲突数据维护时也可确认名称后删除，不要求模型可用；先提交清理任务，由后台核实计算已移除后完成软删除并释放额度，原数据保留。未知结果先对账，不重复创建或释放未确认额度。创建原子预留计算/存储/实例/并发名额；停止释放确认的计算但保留卷/实例占用；软删除释放确认的计算/活动实例额度但保留数据仍计存储；实际永久回收后释放存储额度。创建时可选 CPU 1/2/4/8/16 vCPU 与内存 2/4/8/16/32/64 GiB，数据盘采用平台默认容量；默认 2 vCPU、4 GiB RAM、10 GiB 数据。所选批准规格与模型提供商、模型配置一起预检并冻结到实例，按实际 CPU/内存/存储量原子预留；规格停用或额度不足拒绝创建，不自动替换选择。创建抽屉在CPU、内存、存储选择旁显示剩余额度，实例剩余数量位于运行资源标题旁；超出剩余量的字段标出不足，不另展示额度表格或计量说明；可用量取个人与组织剩余额度较小值，包含已预留资源和保留数据。查询失败或未初始化不能显示为零额度；预览不预留资源，提交时重新原子校验。实例数量为唯一的数量上限，不单独设置运行数量上限；各用户与组织限额、默认值和并发构建保护见第 6.9 节及[配置基线](deployment.md#8-配置与业务规则基线)。

### 6.3 持久化与质量要求

工作文件和已验证 DSH 配置/会话目录持久化，不承诺在途进程恢复。缺卷、标签或初始化权限不匹配时拒绝启动，不补空卷。卷保留与独立备份分别验证。

质量目标：预拉镜像、依赖健康、默认规格下，至少20次创建至ready的P95≤120秒（隔离环境分批方式见测试）；10个并发读用户、持续5分钟的读API P95≤500ms；100次失权试验全部WS≤30秒关闭；DB与已刷盘工作数据RPO≤24h、RTO≤4h。测试记录失败/外部限流，不能仅统计成功样本。这些是验收目标，尚未实测。

浏览器覆盖试点锁定的 Chrome/Edge 稳定版本；关键流程键盘可操作、焦点可见，不仅用颜色表示状态。日志/审计/探测脱敏，不保存秘密和工作正文。保留值见 [部署第 5 节](deployment.md#5-备份恢复与保留)。

### 6.5 角色管理规则（REQ-14）

内置ADMIN包含全部首版权限，MEMBER包含本人实例操作、个人模型管理、组织配置安全摘要和本人审计读取权限；两者的标识、权限和系统属性不可通过页面编辑或删除。自定义角色在单组织内维护，权限从第6.6节固定目录选择，不支持自定义权限表达式、角色继承、多个角色叠加或跨组织授权。

自定义角色具有稳定ID、不可变编码、名称、说明、权限集合、版本、创建/更新时间和已分配用户数。编码为小写字母开头、由小写字母/数字/下划线组成的3～32字符，组织内唯一；名称1～64字符，说明最多500字符；空权限集合合法，代表不具备业务功能权限。角色修改使用期望版本；未知权限、重复权限、通配符和保留编码拒绝。

自定义角色可从当前全部25项权限目录中选择，包括用户、角色、资源配额及模型目录管理；内置ADMIN默认拥有全部权限，治理操作按实际有效权限校验。依赖必须显式满足：实例动作要求instances:read，audit:organization要求audit:read，组织模型写入/校验/撤销及默认项写入要求configuration:read，个人模型写入/校验/撤销要求personal-model:read。缺依赖时返回字段错误并指出所需权限，不静默增加权限。

删除仅允许未分配给任何用户（含待确认、禁用或归档用户）的自定义角色；需要先显式改派角色。角色删除与用户分配并发时必须串行校验，不能出现悬空分配。管理页面显示删除影响并确认，不提供隐式批量改派。

本文“管理员”类操作也包括具备对应有效功能权限的自定义角色；授予用户、角色或组织日志管理权限不授予其他用户工作空间和数据的访问权。Owner是资源归属约束，不是可分配角色；空权限用户仍可认证、查看自身身份和退出，其他业务请求拒绝。

角色详情和编辑按工作空间、工作数据、模型提供商、用户管理、角色与权限、平台配置、操作日志分组，展示权限名称和简短用途。工作数据组单列永久释放存储；查看数据、预览与下载由“查看本人工作空间与数据”授权。权限依赖须显式选择，不自动勾选；不得因目录或文案更新修改现有角色权限集合。

当前用户接口须返回角色标识/名称、有效权限集合与授权版本，前端据此生成菜单和操作控件。实例allowed_actions及can_enter同时结合权限、Owner、状态、健康和配额，前端隐藏按钮不构成授权。直接调用受限API应返回403；跨Owner或跨组织资源保持404；未登录、禁用或已撤销会话返回401。

用户状态、角色分配或角色权限变更须与版本递增、受影响用户授权代次推进、会话/票据撤销和追加审计形成原子安全边界。角色权限更新与已授权业务写入并发时，事务内按当前权限重新检查，不能在撤销提交后使用旧许可接受新意图。Redis故障或缓存命中不能扩大权限，不能仅检查角色名称或浏览器声明。

操作日志记录操作者、目标用户/角色、动作、权限差异、结果、时间、授权版本和关联ID；失败拒绝记录安全原因，不记录凭据、身份提供方原始响应或用户工作正文。新增、编辑、启停用、归档、角色分配与权限变更均须有明确事件；审计写入失败则授权变更回滚。

| 密钥输入 | 内置提供商首次必须提供Key；编辑时留空保留本人当前未撤销Key，显式无效值拒绝。自定义服务可明确选择无鉴权。密钥按组织、Owner、连接、凭据版本及用途绑定加密，复用保留原密文引用，各模型版本独立签发运行密钥。只返回credential_configured和安全状态；Key不进入URL、列表、缓存、操作日志、Terraform state或工作卷。 |
| 同步执行 | 保存不可变版本及同步操作/审计在同一事务完成；提交后后台注册平台模型别名和受限虚拟密钥。外部调用不持有业务事务；任务租约、稳定远端标识与读回核对保证重投不重复注册。超时或远端成功/回写失败为UNCERTAIN/PENDING，不误报同步成功或自动换标识重做 |
| 同步与校验状态 | 本地保存、后台路由同步和真实能力校验分别显示；只有同步确认、凭据未撤销、路由核对及当前版本能力校验有效、目录启用的模型才可创建、应用或推理。默认选择可先随账号保存，可用性仍须经过校验。凭据缺失、权限不足和未知结果不得显示成功。 |
| 持续核对 | 当前版本及仍被默认/实例引用的旧版本定期只读核对冻结路由和虚拟密钥范围；漂移/缺失/未知/过期禁止新用及计费校验，不静默覆盖远端或修复到其他配置。网关核对与同步、真实能力校验分别显示，恢复仅凭读回与有效租约；不作永久不变保证 |
| 账号默认与创建 | 每个模型提供商账号独立保存一个默认模型，规则见第6.8.2节。Portal只选择本人账号并冻结默认模型ID/版本，不静默回退。后端兼容每用户一个个人默认及组织默认的旧解析，不作为Portal创建流程。幂等重放保持首次选择。 |
| 运行与切换 | DSH使用受限账号入口，初始采用冻结的默认模型，可切换同账号可用模型（第6.8.3节）。私有模型不公开给组织其他用户；已有实例通过“更新模型提供商”选择本人有效账号并显式应用其默认模型，不提供组织模型选项或自动回退；受控重启保留原卷，不在工具任务中途静默回退。 |
| 启停与撤销 | 停用立即禁止新用并撤销该连接的入口/运行授权，由系统安全停止使用它的实例；重新启用必须提交替换Key形成新版本，并重新同步与校验。撤销使平台引用立即失效并后台吊销对应虚拟密钥/路由；分别显示本地生效及远端确认。本人复制的真实提供商Key仍须在提供商处吊销，不能把网关吊销作为提供商Key已失效证明 |
| 配额与权限 | 每用户最多20个未删除模型提供商账号及20个选中个人模型；目录上限与API分页限制见接口和配置基线，页面分页见第7.2节。ADMIN/MEMBER默认拥有个人模型读、写、校验、撤销权限；自定义角色按权限授予，不因此获得组织配置或网关管理权限。 |
| 删除与审计 | 账号/模型移除规则见第6.8.1节；历史版本及使用关联保留。保存、同步、校验、默认变更、启停和撤销记录主体、资源、版本及结果；接受事务末尾审计失败整体回滚且不调用远端。 |

账号及模型批量保存须使用同一提供商/API根，事务内完成配额、加密、版本、同步任务与操作日志；任一项失败全部回滚，丢失响应按完整批次幂等重放。只开放选中模型，不自动开放全部官方模型。同步发现不证明协议兼容或推理权限；同步不证明模型支持Responses工具调用，须通过能力校验后才能使用。

验收必须使用两个用户和不同凭据，验证数据库、平台API、运行密钥及实际DSH均不串用；不能仅检查前端隐藏或猜测不出内部别名。

同步支持OpenAI兼容GET /models、Anthropic GET /v1/models（after_id分页）、Gemini GET /v1beta/models（pageToken分页且过滤generateContent），总期限8秒，最多10页/1000项/每页1MiB。上游不支持目录API、密钥无效、超时或分页异常时显示失败和重试入口，不返回半份列表，不推理、不静默回退缓存，不回显或持久化同步时的密钥。选中模型保存为Owner私有目录快照；普通用户及管理员业务接口均不能读取或修改其他Owner私有目录。

#### 6.8.1 模型提供商账号操作

“模型提供商”以独立模型提供商账号为管理单位，包含名称、固定提供商/API根、个人密钥和1～20个允许使用的模型，不能按名称临时拼组。分页与搜索遵循第7.2节；模型默认折叠，展开后显示逐模型校验、账号默认和工作空间使用情况。

添加：下拉选择提供商，填写服务地址/密钥，同步官方列表后搜索、批量勾选或取消模型；自定义OpenAI/Anthropic服务可手动添加ID，明确选择无鉴权。一次提交原子创建整组，重复提交不得创建重复连接。

修改：回填名称和已选模型，密钥不回显；可直接使用已保存的本人密钥同步列表。同步只更新候选列表，保留原选择。保存可增减模型或更换整组密钥；仅修改名称保留模型版本与校验。更换密钥为所选模型生成新不可变版本，后台自动重新同步与校验。提供商与API根固定，更换时新增连接。编辑要求预期版本，冲突不覆盖其他修改。

自动校验：新增模型和更换密钥后的当前版本在同步完成后自动执行流式及工具调用校验，无需点击按钮，关闭页面后仍继续。仅改名或保留原模型不额外触发即时校验；已启用且校验通过的当前个人模型均定期续检，不要求设为默认或已被工作空间使用；未被引用的失败模型提供安全原因和手动重试，不自动反复调用。后台与手动操作共享持久版本租约及每日探测预算，过期租约可恢复，移除、撤销或变更版本后旧任务不得发布成功。表单提示自动校验与定期续检可能产生的少量模型用量；默认选择可以随账号保存，但实际有效校验前不能供工作空间使用。

移除模型和删除账号：有未删除工作空间引用时禁止操作，并指导先更换工作空间模型。无引用时原子清除受影响的个人默认（保留递增版本墓碑）、撤销运行资格并排队删除网关路由/密钥。整组删除二次确认，显示“正在删除”；后台确认全部版本已撤销后自动归档并移出列表，不能把提交成功当作远端清理完成。模型移除要求撤销权限；整组删除要求personal-model:revoke。保留历史快照与审计，物理删除不是页面操作。

被移除的模型立即失去新用资格，后台确认撤销前保留补偿记录。老单模型接口新增/批量新增会登记稳定模型提供商账号，现有连接升级时分别保留密钥和所有运行ID，不因同名或同API根自动合并。

自定义/本地服务在提供商下拉框与账号列表中统一显示“自定义”，仅保留一个入口。选中后通过“接口协议”选择OpenAI或Anthropic；协议用于选择适配器，创建后与账号服务地址一起固定。

#### 6.8.2 账号默认模型

每个模型提供商账号独立设置默认模型。新增或编辑时仅能从本账号保留的模型中选择；默认值随稳定模型ID保存，密钥轮换不丢失选择。创建工作空间只选择模型提供商账号，自动使用其默认模型当前版本，预检通过后冻结ID和版本；默认无效时阻止创建，不暗中替换。已有工作空间不随默认模型变更；显式“更新模型提供商”时同样只选择本人账号，并应用其当前有效默认模型的精确ID/版本。更新弹窗仅列出ACTIVE账号且其默认模型可用的选项；无默认、默认被移除/停用、同步或校验无效、缺少读取权限及账号查询失败均不得提交，不自动选中其他账号。账号之间、用户之间默认值互不覆盖。

#### 6.8.3 工作空间名称与实例内模型切换

创建工作空间可填写名称，留空由平台生成；填写时遵循1–32个字符，支持中文、字母、数字、下划线和短横线的规则。名称校验、提交、幂等重放及名称重复冲突均沿用后端契约，结果未知时保持原名称。

创建只选模型提供商账号，不展示具体模型；使用账号默认模型初始化DSH。DSH模型选择器列出同组织、同Owner、同模型提供商账号下全部可用模型，以模型名称显示，切换无需重新创建实例。模型须启用、未归档/移除、已同步、运行凭据未撤销、目录允许且能力校验与网关核对有效。实例内切换不修改账号默认值和平台资源快照；每次推理重新授权，使用所选模型自己的上下文、输出和响应映射限制。其他用户、其他账号及组织共享模型不可借此访问。默认/锚定凭据撤销后整个实例的账号入口关闭；单个其他模型失效后从目录移除且不能继续推理。

旧实例保持冻结运行版本，普通启动不自动升级；通过明确“更新模型提供商”应用当前批准适配器后使用账号切换功能，保留工作盘。

### 6.9 用户资源配额管理规则（REQ-18）

管理员通过独立“资源配额”导航页（`/app/quotas`）查看和调整用户额度。页面支持搜索用户、按状态筛选、分页，以及逐用户四维“已占用 / 上限”对比和默认继承/单独分配状态。额度按组织与不可变用户 ID 绑定，不随显示名、登录邮箱或角色改变；禁用用户不释放已有资产占用。配额不代表预留宿主机容量，不引入计费、动态容器规格或资源保证。

| 维度 | 单位 | 占用口径 |
| --- | --- | --- |
| 实例数量 | 个 | 已接受创建且未释放的 INSTANCE 预留；停止仍占用，计算删除后释放 |
| CPU | vCPU（接口使用 millicores） | HELD/USED 的 CPU 预留；停止确认后释放 |
| 内存 | GiB（接口使用 bytes） | HELD/USED 的 MEMORY 预留；停止确认后释放 |
| 持久存储 | GiB（接口使用 bytes） | HELD/USED 的 STORAGE 预留，包含停止、删除计算后保留的卷；受控物理回收确认后释放 |

所有维度还须包含恢复账本的有效占用，不能仅统计实例列表或容器状态。已有额度预留仍以数据库为准，未知操作不得提前释放。首版每用户设置四项整数原生单位上限，允许 0 表示该维度不能新增占用；各项不能高于组织总上限。运行默认配置已初始化时，新建用户须在创建事务中按默认规格乘以每用户默认实例数分配实例、CPU、内存和持久存储额度，资源维度最多为组织对应总上限；后续修改运行默认值不覆盖已分配用户额度。既有未分配用户仍按兼容规则继承组织 `max_user_instances` 和组织资源总上限。用户额度仍与其他用户共享组织资源池。独立用户实例上限可以高于统一默认，但不能高于组织实例总上限。实例数量是唯一的数量上限：允许创建的实例均可运行，不再单独设置同时运行数量。创建、启动和重试仍须满足 CPU、内存、存储及宿主机容量校验；并发构建保护仅控制进行中的操作，不限制稳定运行的实例数量。

分配与调整须满足以下规则：

1. 查看需要 `users:read`，写入需要 `users:manage`；普通用户不能修改自己或其他用户的额度，不能通过直接 API 绕过限制。跨组织目标不返回资料，已归档用户不能调整。
2. 页面展示用户、默认继承/单独分配状态、四项有效额度、对应占用及组织上限。单位明确；加载失败禁止保存，保存成功更新显示；版本冲突提示重新读取并确认，禁止静默覆盖。
3. 调整提交完整四项额度与预期版本；未配置版本为 0。降低额度不得低于已预留和实际占用，不自动停止实例或删除数据。先处理资源再降低额度。
4. 创建、启动和需要新增占用的重试，在同一数据库事务和组织配额锁内检查用户及组织剩余额度，再写预留、操作、Outbox 与审计；超额返回 `429 QUOTA_EXCEEDED`，不产生半成品。只释放资源的停止/删除不受新额度阻挡，幂等重放不重复扣额。
5. 配额调整与命令接受使用同一组织锁，防止调整/创建竞争越额；同时调整同一版本仅一项成功。预检反映用户额度不足，最终以命令事务校验为准。
6. 操作日志记录操作者、目标用户、前后额度、版本和 Trace；审计写入失败整笔调整回滚。配额表随数据库备份恢复，恢复占用纳入额度；不提供用户自助抹除账本。

管理员在“资源配额”页调整用户额度；权限、校验与并发规则见第6.9节，页面见第7.1节。

### 6.11 内置 OIDC 登录要求（REQ-02、REQ-13～15）

身份服务运行在 Go API 进程中，issuer 固定为 `HC_PUBLIC_URL/oidc`。提供 Discovery、JWKS、Authorization、Token 和 UserInfo；仅开放已配置平台客户端的授权码流程，强制 PKCE S256、state、nonce 和精确回调 URI。ID Token 使用 RS256，授权码一次使用、60秒有效，Token 5分钟有效。协议与防护数值见[安全设计](security.md#内置-oidc-provider)。

平台登录页提供邮箱、密码、密码显示切换、提交中反馈与重新登录入口；错误后保留邮箱并清空密码，桌面和手机均可使用。未登录或会话失效自动进入登录页，成功后返回原业务路径；仅保留受控站内路径，身份依赖故障提供重试，不循环跳转。登录挑战5分钟有效，绑定安全 Cookie 和表单 CSRF，最多10次失败；Redis 分别限制来源和账号，依赖不可用时拒绝认证。禁用、归档、角色变更及密码重置使旧授权代次失效，旧授权码和 UserInfo Token 不得重新换取权限。

初始版本为平台自身的单组织 OIDC 登录配置，不包含第三方客户端注册、外部身份联邦、MFA、自助注册、刷新令牌、隐式流和通用单点退出。管理员页面只创建平台登录账号；组织身份来源扩展须另行定义协议、数据库与真实验证。

### 6.12 工作空间存储数据管理（REQ-19）

本需求覆盖数据资产查看、保留、备份、恢复与清理。本机已实现工作数据页面、本人只读查询、文件系统用量采集及受控维护记录。独立备份目标和灾备RPO/RTO验收按本次确认范围后续另做。数据资产提供固定目录的只读浏览、文本、Office 与 PDF 预览及限额下载；不支持网页上传、编辑或删除文件。Office 扩展名文件若实际为不超过512 KiB的有效UTF-8纯文本，明确提示格式不符并按文本显示；加密、损坏及超过处理上限分别提示，不将占位文本误报为加密文档。

#### 6.12.1 数据范围与查看

工作数据以不可变存储资产为对象，绑定组织、Owner和原工作空间；停止、软删除后仍能查询本人保留资产，不能因工作空间移出活动列表而失去数据记录。包含工作文件及已声明持久化的 DSH 配置、已完成会话和工具记录；不承诺容器临时目录、内存状态或在途任务恢复。

| 展示项 | 规则 |
| --- | --- |
| 工作空间与归属 | 展示原工作空间名称、Owner本人范围和资产标识；同名工作空间不得混淆，删除后保留原关联 |
| 已分配容量 | 显示冻结数据盘硬容量，以GiB展示；这是用户/系统存储配额的计量基准 |
| 实际数据用量 | 展示来自数据盘文件系统的已用、可用容量和采集时间；文件系统开销可能导致可用量小于分配容量，不能按文件大小简单推断 |
| 采集状态 | 未采集、过期、探测失败分别显示“未采集”“待刷新”“暂不可用”；禁止显示为0或以配额占用冒充实际用量 |
| 资产状态 | 统一展示可用、保留中、处理中、已回收；未知状态显示待核对，不推断数据已消失 |
| 保留信息 | 显示软删除时间、保留截止时间、法律保留状态，以及当前是否满足回收条件；到期显示“保留已到期，尚未回收” |
| 备份信息 | 展示本人资产最近一次备份状态、完成时间、校验结果和备份有效期限；无记录、进行中、失败与成功分别呈现 |

资产状态精简为四种，数据资产列表、详情、数据浏览页及实例详情中的存储状态保持一致；颜色之外必须保留中文状态文字。

| 展示状态 | 标签颜色 | 对应状态 |
| --- | --- | --- |
| 可用 | 绿色 | READY |
| 保留中 | 金黄色 | RETAINED |
| 处理中 | 蓝色 | PREPARING、RESTORING、RECLAIM_PENDING |
| 已回收 | 灰色 | DELETED |

状态筛选提供“全部状态”和上述四项。“处理中”须覆盖准备、恢复和回收待确认三个阶段，按完整匹配结果计数和分页。具体处理阶段仅在数据资产详情的“更多信息”中查看；未知状态使用灰色“待核对”，不并入“处理中”。

“回收待确认”仍表示物理回收尚未核实，主标签显示“处理中”，不得提前显示为灰色“已回收”或返还存储额度。展示合并不改变底层生命周期、权限和存储计额规则。

数据目录只允许本人读取 `/data/workspace` 和 `/data/dsh`，支持运行中、已停止或软删除的工作空间；活动工作空间不得自动停止。运行中通过受信短时sidecar以只读方式复用已挂载的数据卷，不重复挂载块设备；停止或软删除后沿用受控离线只读挂载。目录每页最多100项，文本预览上限512 KiB，Office（docx/xlsx/pptx/odt/ods/odp）16 MiB，PDF 32 MiB，下载64 MiB。Office 在禁用脚本的隔离页面中呈现，工作簿可查看所有工作表；复杂版式或图表提示下载查看，旧版 doc/xls/ppt 仅提供下载。PDF 支持翻页、缩放、适合宽度和选择文字，字体及解析资源由本站提供。预览立即展示加载状态，关闭取消读取和解析，失败可重试或下载原文件；加密及损坏文件给出明确提示。拒绝路径穿越、符号链接和非普通文件，不暴露其他系统路径；文件读取前后检查元数据是否变化，不提供上传、编辑或删除文件能力。

用量采集必须有界，不能通过递归扫描或临时启动用户计算实现。页面可刷新安全元数据；当前配置基线为每60秒采集、5分钟过期、单次5秒超时，调度每10秒最多处理2项；配置及实测见部署和测试文档。停止或已删除资产无法安全采集时保留带时间的最近记录或显示未采集。

#### 6.12.2 归属与权限

成员仅能查看本人资产、备份元数据及固定数据目录；查询至少要求当前有效的 `instances:read` 和Owner关系。跨用户/跨组织对象返回404；禁用、退出或失权后不能继续读取。管理角色与组织审计权限不授予读取其他用户文件、备份内容或任意挂盘的权限。

备份、恢复和法律保留由受信运维身份执行。网页支持本人手动释放已删除工作空间的存储；新增 `instances:release-storage` 权限，必须输入工作空间名称并确认不可变资产。API仅持久化意图，主机操作仍由受信Worker执行。已禁用Owner的资产仍保留并计额，受信运维依据既有治理流程维护，不能为查看数据临时恢复用户访问资格。

#### 6.12.3 保留与配额

停止保留原卷；软删除确认后清理计算与入口，按删除时固化的保留期限保留数据，默认7天、可配置1～365天，已有更长期限不得缩短。保留到期仅改变可回收资格，不自动删除。

创建预留、停止保留、删除保留、恢复保留及回收待确认的资产继续按已分配容量计入用户和系统持久存储额度。删除文件、降低实际数据用量、备份成功或保留到期均不释放该额度；只有物理回收经核实完成后才释放。默认资源调整不扩缩已有数据盘，首版不提供在线扩缩容。备份仓库占用与工作盘配额分别统计，不能将两者相加显示成用户数据盘用量。

存储额度不足时明确提示“存储额度不足，请联系管理员处理保留数据或调整配额”；数据盘满时提示“工作空间数据盘空间不足，请清理本人文件”；宿主机余量不足单独提示联系管理员扩容。上述情况不能以通用模型校验提示代替，不能自动清理文件或跳过保留保护。

#### 6.12.4 备份

备份须核实原资产绑定、Owner、硬容量和存储账本，工作空间计算已确认停止或软删除，且无活动/未知生命周期操作或冲突维护任务。不能把运行中复制、未刷盘数据或成功提交任务视为一致备份。

通过受控运维流程生成加密备份，记录资产/工作空间/Owner、冻结容量、模板和运行版本、完成时间、完整性校验与任务关联ID；密钥、主机路径和工作正文不进入页面或普通审计。失败不覆盖最近一次有效备份，中断后先确认原任务，不能重复标记成功。备份记录只有加密归档完成且校验通过后才显示成功。

数据盘保留与独立备份分别验收。备份仓库保留策略独立于工作空间保留期限，日备份默认保留最近7个成功日期，遵守法律保留和损坏保护；独立故障域及RPO/RTO沿用第6.3节目标，不因存在本机备份而视为满足。

#### 6.12.5 恢复

恢复必须选择已认证且校验通过的备份及明确的目标资产，展示备份时间、来源工作空间、容量、目标、覆盖影响和前置条件。首版仅允许同组织、同Owner、不同工作空间和不同资产、相同硬容量的目标；目标计算已确认停止、无活动或未知任务、运行绑定有效且无法律保留，目标存储额度已预留。原资产缺失、归属冲突、容量不匹配、备份损坏或未能确认停止时拒绝。

执行前加密保存目标原数据并确认目标标识；不能直接覆盖来源资产。恢复中隔离目标入口，任务中断保持“处理中”（详情阶段为恢复中/待确认）并保留配额和原数据保护，按原维护意图对账续做。只有文件校验、绑定与审计完成才显示成功；恢复成功不自动启动工作空间、不恢复旧会话授权、不复活撤销凭据。已软删除来源的数据恢复到符合条件的另一工作空间，不将原软删除实例改回运行状态。

#### 6.12.6 清理与永久回收

用户可以在原生工作空间清理本人文件；平台工作数据中的“删除工作空间”仍为软删除并说明保留数据继续占额度。到期回收由受信运维执行，要求原资产归属与账本可核对、计算已软删除、无挂载/活动/未知任务、无法律保留、保留期限已到且软删除至少满7天，任一不满足均说明阻断原因。

本人手动释放是保留期规则的明确例外：Owner可在工作空间已确认删除后提前结束保留期，不受7天最低期限限制，但不得绕过法律保留、活动/未知操作、绑定和账本核验。须具备当前 `instances:release-storage` 权限，展示将释放容量和不可恢复影响，输入工作空间名称确认；每资产唯一持久请求，重复提交返回原请求。后台核验并确认物理回收后才返还额度，失败或结果未知继续保守计额并按原意图对账。

回收先只读预览目标、容量、可释放额度和不可恢复影响，实际执行须精确确认资产并提供原因。涉及多个资产逐项记录，不通过模糊筛选批量删除。发生超时、外部删除响应丢失或审计失败时保持回收待确认及保守计额，核对物理结果后推进终态；重复执行不重复释放额度。

所有维护记录包含操作者、目标、时间、原因、前后状态、任务/关联ID和结果。审计不含文件名清单、正文、密钥或备份密文；维护意图必须先持久化并审计，不能以界面成功提示代替物理完成。存储回收与备份清理独立执行，回收工作盘不连带删除有效备份。

### 6.13 工作空间插件与 Agent 预设（REQ-07）

Owner可通过DSH“插件”页启停内置可选组合包，安装、启停及卸载第三方DSH组合包；普通npm库不能作为插件安装。配置、依赖、锁文件和缓存随原数据盘持久化，停止或重启不丢失；更改影响同实例全部会话。沿用原生信任提示、版本兼容检查、安装失败回滚和构建脚本确认，不自动批准脚本或豁免版本限制；失败时显示实际原因，不能仅因依赖下载完成而宣称启用成功。

“设置 → Agent 预设”须能加载标准、PTC、极简和创造模式，展示新任务默认项并允许保存。默认项随原数据盘保留，保存使用版本冲突检查；发生冲突须重新读取，不覆盖他人修改。创造模式须在入口就绪前可解析，不能把缺少必需服务的预设显示为可用。

插件管理、配置编辑和设置服务均为运行必需依赖，就绪前须完成挂载。管理所需组件及平台启动覆盖项保持受保护；预设设置不改变平台模型提供商、默认模型覆盖、原生认证或容器权限。第三方代码在当前实例DSH进程中运行，共享实例的数据与权限，网络访问受原出口策略约束。此能力不默认开放平台Git/MCP集成。

### 6.14 个人技能包与迁移（REQ-20）

Portal 工作台提供“技能包”，保存当前用户的个人技能库。可搜索、新建、编辑 `SKILL.md` 和包内其他文本文件、删除、导入及下载。技能包加密保存在平台数据库，按组织和用户隔离；管理员不因此获得他人内容访问权。本功能不修改 DSH 镜像、容器、插件或持久目录，不直接安装到工作空间；用户下载后自行导入 DSH 使用。

创建填写小写连字符名称与用途说明；编辑校验 UTF-8、YAML frontmatter 的名称、说明及布尔调用字段。名称创建后不可修改；附属资源可由 ZIP 导入，也可在编辑器中通过“新建文件”填写相对路径和文本内容添加；支持 `scripts/run.py`、`scripts/run.sh` 等嵌套路径，成功后自动选中新文件。创建须校验整包版本，重名或大小写重名不覆盖，并沿用文件数、大小和用户额度限制。编辑器可选择已有文件，支持查看和编辑不超过 1 MiB 的 UTF-8 文本（如 Markdown、说明、脚本与配置）。二进制文件提示下载查看，不能以文本覆盖。保存仅修改当前文件并校验整个技能包版本，保留其他文件及来源信息；不执行脚本，暂不提供单文件删除。切换文件、关闭编辑器或重新读取时，未保存内容须经确认才可丢弃。工作台不提供自动调用、手动调用设置或相关提示；只管理技能内容和文件。编辑、删除和同步使用版本校验；冲突保留编辑内容并允许重新读取，删除须输入名称确认。

导入支持 Markdown，以及根目录单 Skill、单层包装目录或多个 Skill 目录的 ZIP；每项均须包含有效 `SKILL.md`，多项目录名称须匹配技能名称。先预览名称、说明、资源清单和差异，再确认保存；同名默认跳过，可明确选择替换。新导入项默认关闭两类调用，导入不执行脚本或安装依赖。替换时加密保留上一版包供下载；后续替换覆盖此备份，删除 Skill 同时删除该备份。

限制上传不超过 5 MiB、单文件不超过 1 MiB、每个包最多 128 个文件、解压总量不超过 12 MiB；拒绝穿越、隐藏/绝对路径、大小写重复或冲突路径、符号链接、特殊文件及无效 YAML。个人库最多 200 项、当前内容总量最多 65 MiB。预览加密暂存 5 分钟，每人最多保留 4 个；过期不可应用并在后续请求清理。批量导入须原子提交，失败不留半成品。

从链接导入支持公开 HTTPS `.md`/`.zip` 直链，以及 GitHub 仓库、技能目录（`tree`）和文件（`blob`）链接。直接填写仓库地址时扫描默认分支中的 `SKILL.md`；目录链接仅扫描指定范围，保留技能内的相对资源路径，先预览再确认导入。记录来源、内容摘要和同步时间；同仓库多个技能分别检查更新，只更新当前技能，来源删除或更名不覆盖本地内容。不支持私有仓库、认证链接、带查询参数的下载地址或 SkillHub 市场。

服务端逐跳校验地址、解析全部 DNS 并固定连接公网 IP，禁止本机、内网及保留地址；最多 3 次重定向，普通来源下载总时限 12 秒，GitHub 仓库及 skills.sh 归档下载总时限 120 秒。GitHub 经官方 API 下载仓库归档，仅允许跳转到 GitHub API 和归档域名；归档不限制总大小，最多 30,000 条目，流式写入私有临时文件并在处理结束后清理，只读取技能子目录，不执行代码。所选技能合计不超过 128 文件、解压后 12 MiB、重新打包后 5 MiB，单文件不超过 1 MiB；超限时提示使用具体技能目录或文件链接。一般 Markdown/ZIP 直链仍限 5 MiB。无需改变 DSH 网络配置。

已关联来源的技能可手动检查更新。无变化时保留现状；有变化显示差异文件，本地已修改时提示用户。确认替换才应用，并保留上一版和现有调用设置。预览后原项发生修改、删除或重建时拒绝应用；远端失败保留当前技能，不后台静默更新。

下载单项无附属资源时生成 Markdown；有资源或多选时生成 ZIP，保持相对目录。导出前展示文件清单，提醒检查用户正文中的敏感内容；最多选择 50 项，仍受 128 文件、12 MiB 解压量和 5 MiB 压缩包限制，超限提示分批导出。只导出所选个人技能，不包含会话、运行配置或模型密钥。

权限为 `skills:read`（本人列表、正文和导出）与依赖它的 `skills:manage`（本人创建、编辑、删除、导入与同步），内置角色默认具备两项，自定义角色按需分配。写请求检查 Portal 同源和 CSRF，并在事务内复核权限；记录动作与结果，正文、资源和归档不写审计日志。

### 6.15 可迁移记忆系统（REQ-21）

**接入方式。** 外接开源记忆方案，候选包括 [OpenViking](https://github.com/volcengine/OpenViking)、[Mem0](https://github.com/mem0ai/mem0)、[Graphiti](https://github.com/getzep/graphiti)。通过对应适配器连接独立部署的服务；以库或框架提供的能力由外部服务封装，不把其运行依赖装入DSH容器。每个连接明确方案类型，按需选择，不要求同时部署，也不自动切换。具体开源版本、部署依赖、鉴权、隔离能力及导入导出兼容性须通过适配验证，不将托管产品专有能力视为开源版默认能力。平台保存连接、密文凭据引用、授权命名空间、工作空间绑定及迁移记录，记忆存取和召回由外部服务承担。

| 能力 | 必需规则 |
| --- | --- |
| 连接与验证 | 先从方案列表选择 OpenViking、Mem0 或 Graphiti，支持名称/用途搜索，再填写名称、对应批准服务与凭据；自动填入默认名称和唯一可用服务，支持返回选择；验证连通性、读写范围及版本兼容。凭据加密且不读回；连接可修改、停用和删除，变更后重新验证 |
| 适配能力 | 分别验证OpenViking、Mem0、Graphiti所接版本的写入、召回、更新、删除与导入导出能力；不支持的操作明确标记，不显示为可用。外部用户/会话/图谱分组与平台Owner、实例范围由服务端映射，不能使用客户端自报ID扩大访问范围 |
| 记忆范围 | 个人记忆保存用户明确选择的偏好与经验；工作空间记忆保存当前项目约定和任务摘要。在工作台手动维护，写入先预览确认；本次不自动采集会话或扫描工作目录 |
| 查看与维护 | 支持搜索、查看、编辑、删除，展示内容、类型、来源、所属范围和更新时间。更新带版本检查；错误记忆可纠正，删除后不得继续召回 |
| 关联与复用 | 在工作台关联本人工作空间，检索时明确选择个人或工作空间范围。同Owner新建或重建实例可重新关联；停止、软删除实例或解除关联不删除外部记忆，不自动恢复旧访问凭据 |

| 服务间迁移 | 支持同一服务换实例及受支持适配器间迁移；先导出、再导入目标、核对条数/内容摘要并试检索，确认后才切换绑定。目标失败保留原服务与绑定；迁移预览列出可保留和不可映射字段。Graphiti等图谱方案涉及的实体、关系、事件来源和事实有效时间须随迁移包保留；目标不能表达时提示语义损失并要求确认，不将仅有摘要的迁移标记为完整迁移，不能静默丢失或自动删源 |
| 透明召回 | 展示本次命中的记忆及来源，限制条数与上下文长度；无命中、服务故障和未启用分别反馈。明确记忆可能过时，不把记忆当作最高优先级指令 |

删除连接只解除平台使用关系；永久删除记忆为独立确认动作，展示范围和影响。外部删除超时标记待确认并停止该内容在平台召回，核实完成后才显示已删除。外部存储和调用费用与工作空间卷额度分别展示，不因解绑承诺释放本机存储。

### 6.16 外接知识库（REQ-22）

**产品边界。** 知识库支持外接开源 [Milvus](https://milvus.io/docs)、[Weaviate](https://docs.weaviate.io/weaviate)、[Qdrant](https://qdrant.tech/documentation/) 等方案，作为独立于平台和DSH部署的可选检索后端。每个连接明确后端类型，通过对应适配器接入；按部署需要选择，不要求同时部署，不做隐式切换。Milvus的RAG用法见[官方示例](https://milvus.io/docs/build-rag-with-milvus.md)，Weaviate的生成式检索见[官方文档](https://docs.weaviate.io/weaviate/search/generative)。平台统一管理连接、文档库选择、实例绑定、检索试用及引用展示；向量存储、索引及检索由所选开源服务承担，文档解析、切分、Embedding、重排和回答生成按后端能力由已启用模块、配套开源RAG服务及批准模型服务承担。具体组件、模块及版本在实施前验证，连接成功不等于完整知识库可用。平台不自研检索引擎，记忆与知识库分别授权、绑定与撤销。

| 能力 | 必需规则 |
| --- | --- |
| 连接与选库 | 按所选后端验证地址、鉴权及范围映射：Milvus的database/collection，Weaviate的collection及启用多租户时的tenant，或Qdrant的collection及用于范围过滤的payload字段；同时验证RAG/Embedding配置及所需模块。校验向量维度、索引可检索状态和版本兼容。仅列出当前用户获授权的文档库；支持一个实例绑定多个库。配置有版本检查，换库前展示影响，不能由浏览器自报外部库ID取得访问权 |
| 文档接入 | 原文和版本保存在配套服务的文档存储中，所选检索后端保存向量、片段及来源标识；索引可从原文重建，不能将向量备份替代原文备份。以外部库为语料权威来源；支持平台选择本人工作数据中的文件并预览清单后显式送入外部库，或从外部管理入口维护后同步状态。不得自动扫描全部目录；上传和链接导入只在适配器支持且通过安全校验时开放 |
| 文档状态 | 展示来源、更新时间、解析/索引结果和失败原因；只有已就绪且未撤销的版本参与检索。PDF、Office、Markdown等格式按外部服务实际能力声明；页面可预览不等于文档可被索引，扫描件OCR须单独验证 |
| 语料复用 | 工作台按个人或工作空间范围管理授权语料，多次检索复用同一份外部索引；关联工作空间不重复上传。范围仍受Owner约束，不开放给其他用户或全组织，不向DSH会话和Agent自动注入 |
| RAG检索 | 工作台支持带问题的检索试用，返回相关片段、文档名称、版本、位置和可点击的授权来源引用；服务端限制返回条数与上下文上限，得分仅作相关性参考。无命中时明确说明，不虚构页码或来源；本次不提供回答生成 |
| 原文定位 | 引用打开平台受控预览或批准的外部文档入口，访问时重新校验权限；不暴露服务密钥或永久公开链接。删除或失权后的历史引用显示不可访问，不继续返回缓存正文 |
| 更新与撤销 | 手动同步外部文档/索引状态；重建完成前明确当前使用版本，失败保留最后可用版本并标记过期。删除或撤销优先阻止召回并清除平台缓存，外部未确认时保持待处理，不能靠旧索引绕过撤销 |
| 解绑与故障 | 解除关联保留外部原文和库；永久删除外部文档另行确认。停用连接后停止新的检索；服务不可用、未索引和无命中分别提示，不能宣称已检索私有知识 |

所选后端的database/collection/tenant或payload过滤字段与组织、Owner、语料库的对应关系由服务端映射，检索时强制限定授权范围，不接收用户自报的过滤表达式作为权限依据。跨Owner隔离、文档撤销及原文/片段授权须端到端验证，不能仅凭collection名称或前端筛选实现隔离。

**共同接入与权限。** 权限为 `memory:read/manage`、`knowledge:read/manage`，写权限依赖读取；工作空间关联还需本人实例的配置权限。管理员和成员默认具备本人内容的读写权限，自定义角色显式授予；默认权限通过迁移48同步到已有内置角色。组织、Owner、实例绑定和外部命名空间由服务端推导并逐次校验；管理员管理连接配置不隐式获得个人内容。外部服务须提供可验证的范围隔离，缺少隔离时使用独立凭据/命名空间，仍无法隔离则拒绝接入。写操作采用同源/CSRF、版本与幂等保护，审计记录对象、动作和结果，不记录正文、检索问题及密钥。

连接地址须经受信管理员批准，允许明确登记的私有服务，用户不能借地址配置访问任意内网；校验TLS、目标主机/端口及重定向，凭据仅发给批准目标。发送内容前说明外部服务及其解析/向量模型的数据去向、限额和费用；文档片段与记忆均视为不可信数据，不能覆盖系统指令或自动执行其中的代码。

**工作台与DSH边界。** 按用户确认，本次功能加载到平台工作台：记忆与知识库的连接、维护、导入导出、迁移、检索和引用均在Portal完成。工作空间关联用于内容整理，不表示DSH启用检索；DSH自动调用不属于本次范围。不修改DSH镜像、容器、组合、持久目录或模型请求，不安装插件。用户禁用连接后停止新的平台调用，不自动切换其他服务。

### 6.17 连接器（MCP，REQ-23）

**目标与边界。** 让用户在平台工作台统一连接外部工具与业务系统，减少重复配置，并能明确看到将发送什么、调用了什么、结果如何。入口为“连接器（MCP）”，数据按组织和Owner隔离；平台后端作为MCP客户端，浏览器不直连外部服务。首阶段提供连接管理、工具发现和手动试调用，不修改DSH镜像、容器、配置或数据，不向DSH会话、模型请求自动注入工具。技能包管理任务说明，记忆与知识库管理内容，连接器管理外部工具调用，三者分别授权。

| 能力 | 必需规则 |
| --- | --- |
| 内置目录 | 平台内置29种连接器，提供分类、名称/用途搜索、接入说明、官方文档及配置入口，离线加载目录；目录不代表服务已部署。管理员以 `catalog_id` 将明确批准的兼容MCP服务关联到条目，平台服务固定选择，地址只读；无绑定时展示接入准备，自有兼容地址须经“自定义 MCP”入口填写。内置5种远程OAuth服务的固定地址及授权入口；其余条目仍需兼容服务绑定，CLI与适配服务由管理员独立部署，不改DSH |
| 添加与配置 | 填写名称、认证方式和说明；内置平台服务选择固定地址，自定义MCP填写本人URL；公网HTTPS可自助配置，私网/HTTP须由管理员精确批准；可编辑、复制非敏感配置、启停及删除。首阶段支持远程HTTPS Streamable HTTP，无认证、Bearer或OAuth 2.0 + PKCE；本机Docker测试端点由运维精确批准。保存配置不表示连接可用 |
| 协议兼容 | 按固定协议版本及能力发现流程验证服务，记录服务名称、版本和支持能力。以[2026-07-28传输规范](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http)为基线；2025-11-25兼容须作为独立配置与测试项，不把旧会话行为套用到新版。首阶段不启动stdio命令，不执行粘贴配置中的npx、uvx或脚本；旧HTTP+SSE另行适配 |
| 验证与状态 | 验证地址、TLS、认证、协议与工具发现，展示待验证、验证中、可用、需授权、不可用、已停用及最近检查时间。分别提示凭据失效、版本不兼容、超时或限额；服务可达不等于每个工具可执行。修改地址或凭据后重新验证，不继续使用旧目录授权 |
| 工具目录 | 分页同步工具名称、说明、输入JSON Schema及服务声明的行为提示，区分平台启用状态。全部工具默认关闭，用户显式选用；同名工具按连接ID与工具名区分。目录完整同步后才发布快照，失败保留旧快照并标记待刷新；首次发现不调用工具 |
| 目录变更 | 手动刷新并展示新增、移除及参数/描述变更。新增工具保持关闭；已选工具的定义变更后暂停调用，重新确认才可启用；移除工具立即不可新调用。工具数量、分页或Schema超限时明确失败，不把截断目录标记完整可用 |
| 手动试调用 | 选择已启用工具，按Schema填写并在服务端校验参数；提交前展示服务、工具、参数及外发内容，用户确认后执行。写入、删除、发送消息、付款或行为未知的工具每次额外确认；服务的只读/破坏性注解仅作提示，不能代替授权。首阶段不提供模型自动调用或后台定时执行 |
| 结果与失败 | 展示执行中、成功、工具执行失败、平台拒绝、已取消或结果待确认；区分协议/HTTP错误与工具返回的错误。超时、断连或取消不能证明远端未执行，保留调用ID且禁止自动重试；用户核对外部结果后才能发起新调用，不承诺跨服务恰好一次执行 |
| 配置迁移兼容 | 工作台不展示导入、导出入口。原API保留版本化JSON配置及常见mcpServers远程配置的预览映射；预览服务地址、认证要求、工具选择及不兼容字段，确认后保存，同名默认跳过。导出不含Token、认证头或运行会话；导入忽略凭据并要求重新填写，工具默认关闭、连接待验证。拒绝含stdio命令的条目，不静默执行或降级；资源URI、结果附件和工具描述中的链接不自动抓取 |
| 停用与删除 | 停用立即阻止新调用并撤销平台缓存授权；在途请求尽力取消，但仍可能已产生外部效果。删除连接须确认名称，清除凭据和工具授权、保留脱敏审计；不删除外部系统数据或其他连接。重新启用须再次验证 |

**权限与数据。** 已新增 `connectors:read`（本人连接、目录及调用状态）、`connectors:manage`（本人配置、OAuth授权、验证及工具选择）、`connectors:invoke`（手动调用）；后两项依赖读取，管理权不隐含调用权。沿用工作台规则，管理员与成员默认可管理和调用自己的连接，自定义角色按需授权；迁移49向内置角色授予默认权限，不自动扩大自定义角色授权。管理员不得借配置管理读取他人凭据、参数和返回内容。调用时及出站前复核当前Owner、权限、连接版本、目录版本和工具授权；撤销后旧确认不能继续发起调用。

凭据按本人独立加密保存且不明文读回，更换服务地址须重新输入凭据，不复用平台登录Cookie、模型Key或记忆/知识库凭据。地址、DNS、端口、重定向与认证头均按受信出口策略校验；私有网络仅放行精确批准目标，拒绝云元数据和未批准回环地址。调用参数和结果只在当前授权页面展示，默认不存正文；持久调用记录仅保存调用ID、连接与工具版本、发起人、时间、状态和脱敏原因。工具说明及返回内容视为不可信文本，禁止执行HTML/脚本或覆盖平台指令。

**首阶段限额与交互。** 每人最多50个连接；每连接最多1000个工具、分页最多100次且拒绝循环游标；发现总时限10秒，调用默认60秒、硬上限120秒；请求与结果各不超过1MiB，超限返回明确原因并保守标记执行结果。每人最多3个并发调用、同连接默认1个，调用入口每分钟最多30次。桌面/手机列表遵循统一搜索与分页，展示名称、服务、认证/健康状态、工具数及最近检查；详情分为工具、配置、调用记录，提供空状态、错误恢复及进行中反馈，不展示虚假进度。

**OAuth 授权。** 内置 Ardot、Notion、OpenAlex、滴答清单及企查查的授权入口，企查查完整接入规则见第6.17.2节。用户点击“授权连接”，在官方页面登录后自动返回工作台，保存本人凭据并验证连接；工具默认关闭。自定义 MCP 通过 RFC 9728 元数据发现授权服务；使用授权码、PKCE S256、一次性 state、精确回调与资源绑定，支持动态注册及管理员预配置客户端。state 有效10分钟，绑定组织、用户、登录会话、连接版本和地址；拒绝取消、过期、重放、跨账号及配置变更回调。访问/刷新令牌及客户端密钥加密保存且不读回，厂商支持并签发刷新令牌时到期前刷新，刷新令牌轮换原子保存；无刷新能力或失效时提示重新授权，401不降级匿名且不自动重试工具。停用阻止使用，普通连接删除擦除本地凭据及待授权请求，不承诺撤销厂商账号上的授权；企查查OAuth解绑须满足第6.17.2节的远端撤销要求。腾讯文档仍按官方个人Token方式接入。

**后续阶段。**Resources与Prompts的发现、授权读取及订阅，受隔离执行器管理的stdio服务，连接市场与团队共享，以及Agent自动调用分别立项；不得用连接验证通过替代这些能力。[工具规范](https://modelcontextprotocol.io/specification/2026-07-28/server/tools)作为目录、调用及错误契约参考。

#### 6.17.1 OAuth部署与厂商验收

平台回调固定为 `HC_PUBLIC_URL/v1/connectors/oauth/callback`，源站、TLS证书、登录会话及网关须一致。公网部署使用实际可访问的HTTPS域名，并按厂商要求登记完整回调地址；本机部署仅在浏览器和服务位于同一台机器时使用厂商接受的 `localhost` 或 `127.0.0.1` 地址。自定义 `.localhost` 子域名不保证被厂商接受；不能只替换授权请求的回调，或把远程平台回调设成用户电脑的localhost。使用本机HTTP回调须符合平台自身登录与会话部署约束，不因此开放公网HTTP。

按实际协议声明请求scope、resource及grant，动态注册使用本平台应用名称及独立客户端配置。厂商拒绝回调、注册或scope时，页面给出脱敏原因和配置指引，保留当前连接供修改重试，不展示为已授权，也不自动切换认证方式。

每家厂商分别验收元数据发现、客户端注册/配置、系统浏览器登录与用户同意、平台回调、工具发现及至少一项获授权工具的显式调用。支持刷新时验证真实令牌轮换及重启后恢复；不支持时验证到期重新授权。模拟OAuth测试、注册HTTP 201、授权页HTTP 302及用户取消回调均不能代替完整厂商验收；记录厂商、环境、协议版本、脱敏证据与未覆盖范围，验收证据必须来自本项目实际执行。对应TC-106。

#### 6.17.2 企查查完整接入（扩展交付）

由平台Go连接器直接接入企查查官方OAuth与MCP服务，提供一张企查查卡片；完整接入包含以下要求，不能以当前单一企业信息地址代替五类服务交付。

| 能力 | 必需规则 |
| --- | --- |
| 双模式认证 | 提供“授权连接”和“使用API Key”入口；OAuth使用DCR、授权码与PKCE S256，issuer为 `https://agent.qcc.com`，scope为 `mcp:tools`。API Key从厂商官方页面获取，加密保存后以Bearer发送，不依赖OAuth回调；回调不可登记时提供API Key指引，仍须用户主动选择和提交，不能静默降级 |
| 回调与配置错误 | 使用本项目 `/v1/connectors/oauth/callback`。允许的回环地址或正式HTTPS回调须经厂商接受；自定义本机域名被拒绝时提示白名单/部署配置原因，不建议用户关闭TLS校验 |
| 五类服务 | 固定连接企业信息 `/mcp/company/stream`、企业风险 `/mcp/risk/stream`、知识产权 `/mcp/ipr/stream`、经营信息 `/mcp/operation/stream`、人员信息 `/mcp/executive/stream`，均属于 `https://agent.qcc.com`；分别使用 `company__`、`risk__`、`ipr__`、`operation__`、`executive__` 工具前缀，防止同名冲突；不接收用户任意追加目标 |
| 共享凭据与资源绑定 | 同一Owner的企查查连接管理一份当前认证，不跨用户共享；校验各服务保护资源元数据、授权服务器及凭据适用范围，不因主机相同就把令牌发送到未授权资源，必要时要求重新授权。切换OAuth/API Key时原子替换认证，清理旧待授权事务、目录快照及工具授权；失败保留原认证，不混用两套凭据 |
| 部分类别可用 | 分别显示五类服务的可用、无权限、故障和未验证状态及最近验证时间；一类失败不隐瞒其余成功类别。各类别目录须完整发现后才发布，失败类别保留旧快照供查看但禁止新调用；部分可用不能标记全部可用，不自动申请额外权限或额度。工具默认关闭，仍须用户选择与逐次调用确认 |
| 刷新与重启 | OAuth到期前刷新并原子保存最新访问/刷新令牌及客户端信息；跨请求、进程或副本使用持久协调，防止轮换令牌被并发刷新或解绑覆盖。重启后恢复本人有效认证与工具选择，再校验当前权限、资源及目录；无需因进程重启重新登录。API Key模式不执行OAuth刷新 |
| 认证失败 | 401仅允许发现/验证等不执行工具的请求刷新后重试一次；刷新无效时要求重新授权。工具调用收到401、超时或断连均不得自动重试，结果按是否已出站保守判断，并提示核对外部结果；不把上游自动重试策略用于可能产生副作用的调用 |
| 停用与解绑 | 停用先阻止新调用并尽力取消在途请求。删除OAuth连接须名称确认，先封闭本地使用并协调刷新，再远端撤销最新refresh token，确认后清除本地凭据、待授权事务与工具授权。撤销失败或结果未知时保留加密凭据及待撤销状态供显式重试，保持不可调用，不误报已解绑；厂商明确报告令牌已撤销可视为完成。API Key删除仅清除本地凭据，说明远端Key须在厂商处另行撤销 |

验收要求OAuth与API Key分别完成真实账号接入，并按账号获授权范围对五类服务各至少调用一项工具；无权限类别须明确记录，完整五类验收需准备具备相应权限的测试账号。补充并发刷新/解绑竞争、刷新撤销、进程重启和旧入口失效证据；工具数量以本项目实际发现为准。TC-107～109覆盖双模式、聚合和生命周期；本项目验收范围为工作台手动调用，模型自动调用另行立项。

工作数据位于用户功能区，紧邻工作空间；包含活动与保留资产，支持按原工作空间名称、状态和保留状态筛选，按统一分页规则展示。点击资产名称进入独立数据浏览页，左侧以 `/data` 为根节点展开 workspace 和 dsh，逐级进入目录。运行中、停止或软删除的数据盘均可只读浏览，预览格式与限额见第 6.12 节，不提供写入和单文件删除。桌面与手机均区分加载、空结果、无权限和请求失败；文件行显示类型、大小和更新时间。

Portal 工作台新增 `/app/skills`，位于工作数据与模型提供商之间。列表、编辑、导入预览和导出确认支持桌面与手机；按权限显示入口与操作，明确加载、空结果、错误和并发冲突。

Portal提供 `/app/memory`、`/app/knowledge` 两个用户入口，支持连接/内容列表、导入迁移或文档状态、检索试用和原文授权预览。页面直接提供工作台管理与检索操作，关联工作空间仅保存内容使用关系。连接配置与内容操作按权限区分，桌面/手机均提供空、加载、失效、失败和重试状态。DTO与公开API已同步OpenAPI；本次不提供DSH自动调用，详见[实施记录](context-implementation.md)。

工作台“连接器”位于技能包之后，路径 `/app/connectors`，按 `connectors:read` 显示入口。`/v1/connectors` 管理本人配置；验证、目录同步、工具选择、调用及导入导出为显式操作，支持按调用ID读取状态。DTO、错误码与版本/幂等契约见OpenAPI，运行与验证见[实施记录](connectors-implementation.md)。

“管理”分组按用户管理 → 角色与权限 → 资源配额 → 操作日志 → 平台配置排列，桌面侧栏与手机菜单保持一致。菜单与按钮按有效权限展示，具体路由以[前端架构](frontend.md)为准。创建使用抽屉，提交中禁止关闭和重复提交，取消不产生实例。平台配置不提供模型管理；帮助与支持保留单一入口。不引入模板商城、组织中心或报表系统。

### 7.2 统一分页与搜索

所有分页列表默认每页10条，可选20或50条；显示总条数、当前页和总页数，提供首页、上一页、下一页及尾页。尾页使用 `>>` 图标，保留“跳到尾页”无障碍名称。空结果按1/1页展示；首页/尾页和加载期间禁用相应控件。

搜索、筛选及每页数变化回到第一页；后台刷新保持当前页，删除或总数减少导致越界时回退有效页。加载错误保留重试/返回首页入口。提供商搜索覆盖全部账号后分页；用户、角色、实例和日志按API授权范围统计，不能先取一页再伪装全量搜索。API默认值、上限及兼容游标以[接口契约](../api/openapi.yaml)为准，与页面每页10条分别定义。

工作空间与提供商使用一致的搜索框、图标、刷新按钮和响应式尺寸；提供商搜索放在右侧，手机适配可用宽度。工作空间按名称前缀搜索，提供商按账号或模型名称搜索，清空后恢复列表。

### 7.3 视觉与交互

品牌统一为DSH Cloud，沿用已确定的DeepSeek Harness参考风格。统一列表、工具栏、按钮、表单和状态样式；模型厂商匹配各自Logo，自定义服务使用通用图标。页面只保留完成任务所需文案，费用提示、删除保护、错误原因及恢复动作必须清楚。桌面/手机无页面水平溢出，键盘操作和减少动态效果符合第6.3节。

### 7.4 操作日志

操作日志应回答谁、何时、对哪个对象执行什么操作、结果如何及哪些值发生变化，提供操作/结果/时间/对象筛选。配额变化展示四项资源原值与新值；角色、权限、状态变更按已保存元数据显示。只开放明确允许的字段，禁止展示密钥、密文、原始请求和内部报告。成员仅查看自己操作或自己资源的记录；组织范围仍需audit:organization权限。缺失的历史详情不推断补填。

界面、组件及客户端命名统一使用“操作日志”。兼容路径 `/app/audit`、`/v1/audit-events`、权限 `audit:read` / `audit:organization` 和数据库审计字段继续沿用；底层审计写入/归档职责不因页面更名改变。

### 7.5 接口范围

接口：当前用户及有效权限、用户列表/新增/详情/编辑/状态/归档/角色分配/配额查询与调整、角色列表/新增/详情/编辑/删除、固定权限目录，以及初始化预检、模型配置写入/校验、批准模型目录、实例创建/列表/详情/启动/停止/软删除/操作查询/安全访问/配置应用。已有接口目录和结构以 [API 说明](api.md) 及 [OpenAPI](../api/openapi.yaml) 为准；REQ-13～18接口、DTO、模型协议与授权版本以结构化契约和失败fixture核对。所有变更由服务端鉴权、CSRF/Origin校验并审计。

REQ-19通过API-077～079提供本人存储资产列表、详情和备份元数据查询，API-081～082只读浏览固定数据目录；Owner鉴权、分页及脱敏字段与OpenAPI同步。用量由Worker采集，API-080提供Owner明确确认后的手动释放；文件浏览复用受信主机边界，不将CLI或主机凭据交给网页。

REQ-20 使用平台 `/v1/skills` 资源接口，导入预览、来源获取、确认应用、导出及版本更新接口见[后端契约](backend.md#个人-skill-库)。数据独立于工作空间，DSH 不新增 RPC 或插件。

平台路径和模型/预检/默认项/安全重试等契约见 [API](api.md) 与 [OpenAPI](../api/openapi.yaml)。平台协议、默认值和数据库约束已固定，见 [配置基线](deployment.md#8-配置与业务规则基线)、[对象设计](design.md#8-面向对象详细设计) 与 [运行适配](backend.md#12-运行适配与外部契约)；上游固定镜像兼容性在 D0 契约测试验证。

### 7.6 工作空间列表与实例详情（REQ-05、REQ-12）

工作空间列表使用与模型提供商一致的分隔列表和工具栏。每行展示空间名称、真实状态、CPU/内存/存储以及“提供商 · 模型”，显示名对应实例冻结的模型版本，不追随账号后续默认值或模型头版本。提供商名称缺失时仅显示模型，不推测厂商；真实模型名称缺失且仅有内部路由时显示“模型信息暂不可用”，不直接展示 `hc-…-v…`。未筛选的列表成功加载且为空时，在“暂无工作空间”下显示“创建第一个实例”描边按钮，复用创建抽屉及权限；加载、查询失败、筛选无结果或缺少创建/启动权限时不显示。

实例详情顶部提供返回、刷新、实例名称、真实状态及进入、启停、更新提供商、删除操作；可操作性仍按当前权限、实例状态和服务端返回决定。运行资源展示CPU、内存与存储，模型区展示提供商与真实模型名；不展示“模型配置说明”及“打开模型提供商”按钮。

实例列表和详情共用以下状态标签规则，桌面与手机一致，始终保留中文状态文字；未知状态使用灰色“待确认”。

| 实例状态 | 标签颜色 |
| --- | --- |
| 创建中 | 蓝色 |
| 启动中 | 青色 |
| 运行中，已就绪（ready=true） | 绿色 |
| 运行中，未就绪（ready=false） | 金黄色 |

“运行检查”按需展开应用、存储、配置、访问和模型健康；“实例信息”按需展开创建/更新时间、存储状态、保留期限、模型配置版本、实例编号及内部模型路由。最近操作显示中文动作、状态、真实执行阶段与安全错误；失败重试沿用权限和幂等规则，进度读取失败可重新加载，不生成估算进度。375px手机和桌面均应正常换行，无页面水平滚动。实例详情不展示环境连接横幅或长期驻留的成功提示。

## 10 环境输入与验证边界

部署必须配置内置 OIDC 的 HTTPS origin、客户端秘密及 RSA 签名私钥，以及受控 Terraform CLI/Provider、固定镜像与模板、模型账户、主机和备份路径，完整清单见配置基线。它们是受控环境输入，值不包含在仓库中；D0 负责固定运行 manifest 与真实适配 fixture。不要在聊天或仓库粘贴密钥。

当前仓库包含平台源码、固定 Terraform 模板、本地部署脚本和验证记录；正式安装包及完整验收仍待完成。依赖可访问性按实际环境预检，不能将一次工具检查作为永久部署证明。
