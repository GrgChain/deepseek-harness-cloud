# 工作台连接器（MCP）实施说明

更新日期：2026-10-26。对应REQ-23、TC-102～109。本文说明当前实现；需求与验收条件见[第6.17节](requirements.md#617-连接器mcpreq-23)，执行状态见[测试验收](testing.md#3-需求追踪)。

| 企查查 | 当前只有企业信息MCP固定地址及通用认证能力；双模式专用流程、五类聚合与远端撤销解绑待实现 |

## 使用流程

1. 在 `/app/connectors` 点击“添加连接器”。选择已配置的目录服务，或通过“自定义MCP”填写本人的HTTPS地址；目录服务地址只读。
2. 无认证/Bearer连接填写必要凭据并保存，再点击“验证”；OAuth连接点击“授权连接”，在厂商页面登录同意后返回，平台自动验证。
3. 在“工具与记录”中选择需要启用的工具。首次发现的工具默认关闭，发现流程不执行工具。
4. 试调用时填写JSON参数、检查预览并确认外发内容；写入、删除、发送或行为未知的工具额外确认。结果正文仅在本次响应与页面展示，记录保留脱敏状态。

授权开始失败保留表单，重试更新已保存连接；官方返回后显示就绪、验证未通过、取消或未完成提示，并清理工作台URL中的提示参数。授权码不进入工作台URL。复制连接不复制凭据，重新启用或修改认证后须验证。

## 目录与服务配置

目录由 `services/internal/connectors/catalog.json` 编译嵌入，提供名称、说明、类别、厂商文档及接入准备。`catalog_id`关联平台服务与目录条目；个人公网HTTPS无需预先登记，私网或HTTP精确例外由管理员配置。

Ardot、Notion、OpenAlex、滴答清单及企查查默认提供固定OAuth服务地址。管理员已有同目录绑定或保留ID时保持原服务，不覆盖。其他未绑定条目只展示接入准备，不能保存占位连接；自有兼容服务须从自定义入口添加。

专用认证头、URL凭据、旧SSE或CLI服务须经独立兼容HTTP MCP适配服务接入。页面只接收实际所连服务的凭据，不能把未支持的厂商认证直接当作Bearer使用。配置格式和例外规则见[部署与复验](../deploy/connectors/README.md)。

Bearer及OAuth令牌使用`connector-credential`上下文加密；授权事务使用`connector-oauth`，两者均参与密钥轮换。参数和结果正文不持久化；列表及配置导出不返回凭据、客户端密钥或授权事务秘密。

## OAuth流程

`POST /v1/connectors/{id}/oauth`校验管理权限、CSRF和配置版本，返回厂商授权URL。授权码流程使用PKCE S256；动态注册支持`none`、`client_secret_basic`、`client_secret_post`，无法动态注册时按精确服务URL使用管理员私有客户端配置。自定义服务通过RFC 9728路径级/根级保护资源元数据发现issuer，并验证资源绑定及授权服务器元数据。

回调固定为 `HC_PUBLIC_URL/v1/connectors/oauth/callback`，不从请求Host推导。state保存摘要，有效10分钟，并绑定组织、Owner、当前Portal会话、连接版本及完整目标；PKCE verifier与客户端上下文加密保存。回调在交换授权码前消费state，不重试授权码；认证成功后只发现工具，不自动启用或调用。

访问令牌有效期不足30秒时，若有refresh token则刷新并持久保存轮换结果；刷新无效或没有可用刷新令牌时要求重新授权。当前按Owner事务锁串行化刷新。OAuth出站请求限10秒、响应64KiB，同样执行DNS/IP固定、TLS校验、禁用环境代理与重定向；MCP私网例外不会自动放行整个OAuth域名。

当前删除只擦除本地凭据、工具快照及待授权事务，保留脱敏调用记录，不会远端撤销厂商授权。企查查专用远端解绑属于[待交付要求](requirements.md#6172-企查查完整接入扩展交付)。

## 调用与安全边界

配置或认证变更清除原工具授权；完整发现后发布目录快照，新增工具保持关闭，定义变化的工具暂停授权，移除工具不可新调用。调用前重新发现并比较定义，出站前复核Owner、权限、连接版本、目录版本、启用状态、工具选择和取消申请。

凭据只向已确认目标发送；所有DNS答案须符合策略，再固定拨号IP。拒绝云元数据、未批准私网、重定向及环境代理，TLS正常验证。Schema拒绝外部加载、递归引用和超限结构；返回内容按不可信文本处理，不执行HTML、脚本或附件链接。

每人最多50个连接、3个并发调用，同连接1个；每连接最多1000项工具/100页；发现10秒，调用默认60秒/上限120秒，请求与响应各1MiB。目录失败保留旧快照但禁止调用。管理和调用入口各30次/分钟。

调用先持久化意图再出站，幂等键绑定连接、版本、工具和参数，同键重放只返回原状态。工具不自动重试；出站后超时、断连或取消保守标记“结果待确认”。停用/删除阻止新调用并尽力取消在途请求；响应返回前再次复核权限及配置，失权或变更时不返回正文。
