## 6 测试驱动开发

开发以一个可观察行为为粒度：从REQ/UC/TC选场景→写断言并运行观察预期失败（Red）→只实现满足该行为的代码（Green）→保持测试通过重构（Refactor）。失败必须来自缺失行为，不是语法/依赖错误。修复缺陷先加复现测试；新增规则与错误分支先加测试，禁止实现完成后补一组镜像测试冒充TDD。

需求/对象/API尚未清晰时先写契约fixture澄清。外部集成采用失败契约测试→固定版本最小适配→真实边界回归；DSH原生凭据通道先由D0原型证明，不能靠Fake宣布可行。提交/PR说明关联REQ/TC、首次失败原因、通过命令和仍未执行的真实验证，不要求保存含秘密的失败日志。

| 层级 | 隔离对象/依赖 | 优先失败测试 | 通过后仍需 |
| --- | --- | --- | --- |
| 领域单元 | Clock/ID可控，无IO | 状态转换/Owner/撤销/健康过期/原卷不变量 | 应用事务验证 |
| 应用用例 | 规则对象及外部端口 Fake，真实 pgx 接受事务 | 提交失败无外部动作、同Key快照、Unknown不当NotFound | 真实PG约束/并发 |
| 数据集成 | 独立PG目标17与真实Redis7.4 | 并发配额/唯一/失租/原子消费/探测预算 | Terraform/Docker故障验证 |
| HTTP契约 | httptest、OAS请求/响应fixture | Cookie/CSRF、分页、错误/版本/未知字段 | 浏览器真实Cookie和跨域 |
| 前端行为 | Vitest 注入 fetch、Playwright 合成 HTTP fixture | 同Key恢复、INVALID/401/403、秘密清理、焦点 | Playwright真实运行 |

## 7 关键失败场景

| 场景 | Given / When | Then |
| --- | --- | --- |
| 同Key/default变化 | 已接受{}，默认模型改变；重发同Key | 原instance/op/首次快照；改显式名称返回409 |
| 配额并发 | 仅剩1名额，两主体同时提交 | 只1接受，其余429；失败事务无Outbox/半条账 |
| 外部迟到 | Workspace登记或Terraform成功、DB回写失败且租约过期 | 新Worker按同Owner/name找回；旧租约回写0行，无第二资源 |
| 票据竞争 | 同票据两个并发POST；另一浏览器无Cookie | 合法浏览器最多一次成功；异浏览器403且无会话 |
| 缺卷竞争 | 检查后卷被移除/设备卸载 | entrypoint标记检查失败、不运行DSH、不初始化空卷 |
| 配置撤销 | 更新途中共享credential被撤销 | 阻断入口与配置继续，安全停止；不回滚撤销Key |
| Redis重启 | 已接受任务仍在，限流键丢失 | PG操作/配额保留，限流重建前阻止新高成本请求 |
| 恢复旧DB | 主机存在快照时间之后资源 | 先全量对账/隔离，保守占额，无自动创建/删除 |
| 最后管理员竞争 | 两个ADMIN并发禁用或降级对方 | 串行重检，至少一名ACTIVE ADMIN保留，不产生全部失管 |
| 角色撤销与业务写入 | 业务请求读取旧许可后暂停；另一事务收紧角色权限 | 事务内重新校验；撤销提交后旧请求不能接受新意图，审计与撤销原子提交 |
| 身份供应未知 | IdP已创建账号但平台回写失败，再次提交原请求 | 保持同一供应操作核对，不创建第二主体；授权完整确认后才转ACTIVE |
| 网关目录与能力不一致 | 别名可列出但模型不支持Messages工具/流式，或Key无调用权限 | 校验失败，不允许设为DSH默认；不把HTTP 200或目录成功当作模型可用 |
| 网关失效与回退 | 平台模型网关超时/吊销密钥/额度耗尽，或路由修订变化 | 显示明确降级/重新校验要求，不切未批准模型或直连；旧快照和原文件保留 |
| 私网网关旁路 | 批准网关解析到非批准IP，或请求其他私网端口 | API及DSH出口共同拒绝，无通配私网放行或TLS验证关闭 |

Redis重启后固定窗口计数丢失会放宽流量：API检测run_id变化/连接重建后高成本入口冷却120秒，PG持久预算仍有效；首次启动也冷却。此规则需TC-34/43验证，不把缓存重建等同于限流状态已恢复。
