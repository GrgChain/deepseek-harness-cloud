# DSH Cloud 前端技术架构

版本：V0.1。实现目录为`apps`；页面围绕工作空间、个人模型和管理操作组织，环境名称、连接成功提示及协议实现细节不常驻展示。

## 1 技术栈与工程边界

React 19、TypeScript、React Router 7、TanStack Query 5、Ant Design 5、Lucide图标、Vite 7。运行工具为Node.js 24，版本范围及锁文件见package.json/package-lock.json。Vitest用于请求和状态单元测试，Playwright用于桌面/手机及真实账号流程。前端调用同源平台API，不直接访问数据库、Docker、Terraform或外部模型提供商。

后端内置OIDC负责邮箱/密码页面和协议端点；SPA只发起BFF登录跳转并读取服务端会话。模型接入通过平台Go模型入口，用户不安装代理SDK、不填写代理管理凭据。

## 2 页面与权限

| 路径 | 页面与主要操作 | 授权 |
| --- | --- | --- |
| /app/instances | 工作空间筛选、创建、实例进度、进入/启停/删除 | instances:read及各命令权限；本人Owner |
| /app/instances/:id | 实例详情、操作状态、诊断、显式应用模型版本 | 同上，服务端重新验证归属 |
| /app/skills | 个人 Skill 创建、编辑、链接同步、导入导出和下载 | skills:read / skills:manage；仅本人内容 |
| /app/models | 添加本人提供商Key、编辑/启停/校验/撤销、个人默认及归档 | personal-model:*；管理员无隐式读取其他用户的权利 |
| /app/users | 新增本地账号、查询/编辑、分配角色、重置密码、启停和删除 | users:*及角色绑定权限 |
| /app/roles | 自定义角色、固定权限目录、有效权限与版本冲突 | roles:*；内置角色及最后管理员保护 |
| /app/quotas | 独立资源配额导航页、用户搜索/状态筛选/分页、四维占用及额度查看与调整 | users:read / users:manage |
| /app/settings | 默认运行资源、实例上限、数据保留期限及按需展开的运行检查 | configuration:read；修改另需 defaults:write |
| /app/audit | 脱敏事件查询及关联操作 | audit:read |
| /login | 登录入口、当前账户、退出 | 同源BFF会话 |

“管理”分组固定顺序为用户管理 → 角色与权限 → 资源配额 → 操作日志 → 平台配置，桌面侧栏与手机抽屉共用同一菜单定义。导航和操作按钮由当前有效权限决定；隐藏/禁用按钮只改善交互，服务端承担真实授权。当前会话失效后清理用户缓存并转到登录，不使用旧角色作为继续写入的依据。

## 3 模块与数据流

用户管理使用标准表格，按用户/联系邮箱、角色、状态、最后登录、操作分列。标题右侧新增用户，状态/角色筛选位于工具栏左侧，共用搜索和刷新组件位于右侧。点击姓名查看详情，“编辑”作为直接操作，角色分配、启停、密码操作和删除收纳至“更多”。窄屏表格内部横向滚动，操作列固定在右侧，页面本身不横向溢出。

PENDING_IDENTITY 用户行提供“重试并启用”入口。身份凭据确认后自动启用；凭据尚未创建时可在用户编辑中修改联系邮箱以同步更新初始登录名。身份供应与登录名修改串行核对，凭据已创建后拒绝修改登录名；启用用户后再编辑联系邮箱仅更新联系信息。

角色与权限沿用用户管理的标准表格及搜索/刷新工具栏，角色名称和编码分层展示，点击名称查看权限。详情按功能分组显示已拥有权限、分组数量、总权限数和分配用户数，使用中文名称和勾选标识；未知权限保留编码，编辑仍使用复选框。操作列固定在右侧，保留“编辑”，删除收纳至“更多”；内置角色禁止编辑与删除，已分配用户的角色禁止删除。仅有读取权限时隐藏新增和写操作。

用户管理中的角色筛选和分配使用 `GET /v1/users/role-options`，仅需 `users:read`，不请求完整角色目录。角色选项加载失败时显示可重试错误，新增/分配表单禁止保存；角色选择保留当前用户的角色名称，支持搜索及滚动分页。

`src/main.tsx`是浏览器入口，`src/app/`组装全局Provider、主题、样式和路由导航。`src/features/`按业务划分页面和紧密耦合组件；`src/api/`集中类型化平台请求客户端，`src/shared/`放置可跨业务复用的组件与Hook，`tooling/`存放Vite本地访问适配，端到端浏览器用例位于`tests/`。

```text
apps/
  src/
    app/                    # Portal组合、全局Provider、主题和样式
    api/                    # 身份、工作空间、设置、模型、管理等HTTP客户端
    features/
      workspaces/            # 工作空间列表、详情、命令和创建额度提示
      models/                # 提供商列表与账号编辑
      resource-quotas/       # 系统/用户配额及格式化
      settings/              # 平台设置和运行默认值
      management/            # 用户与角色
      storage/               # 数据资产管理
      operation-logs/        # 操作日志页面与展示格式
    shared/
      components/            # 分页、搜索、提供商标识
      hooks/                 # 会话失效、短暂通知
  tooling/                   # Vite本地访问适配和单元测试
  tests/                     # Playwright页面及端到端测试
```

跨业务的会话过期处理位于`shared/hooks/use-expired-session.ts`，API错误类型独立于设置客户端；配额格式化逻辑不依赖额度编辑对话框。业务页面依赖`api`和`shared`，共享代码不反向依赖具体页面，以免建立跨页面导入链。

实例与数据资产状态标签统一由`shared/components/resource-status.tsx`提供，复用Ant Design预设颜色和中文文字。列表、详情、数据浏览及实例存储信息使用相同组件；数据状态精简为可用、保留中、处理中、已回收，准备/恢复/回收待确认合并为蓝色处理中，具体阶段在数据资产详情的“更多信息”内查看。状态筛选使用同样四项，PROCESSING由服务端合并三阶段后计数和分页；原始状态继续用于操作保护。实例颜色同时考虑观察状态和`ready`，运行未就绪使用金黄色。具体颜色及未知状态规则以[资产查看](requirements.md#6121-数据范围与查看)和[实例展示](requirements.md#76-工作空间列表与实例详情req-05req-12)为准。

`src/api`按身份、实例、访问、配置、个人模型、治理拆分客户端。组件不拼接任意请求目标或持有启动Token；客户端统一处理安全错误、CSRF、AbortSignal、版本与幂等键。请求响应类型与[OpenAPI](../api/openapi.yaml)一致，命令返回202后通过持久操作继续跟踪。

查询键包含用户及版本作用域；退出时移除账户业务缓存。读取可按需要重试，创建/启停/撤销等写操作不自动生成新幂等键重放；失联时保留原操作标识并查询结果。列表、详情、预检与操作状态在成功写入后失效刷新；长请求可取消，切换Owner不得复用旧数据。

## 4 个人模型操作

用户从数据库批准目录选择OpenAI、Claude、Gemini、千问、DeepSeek、Kimi或Z.AI，输入本人API Key。新连接必须提供Key；同提供商/地区的编辑可留空复用，切换提供商或地区必须换Key。输入值只在当前表单内短暂存在，提交成功、取消及关闭抽屉后清空，不写URL、localStorage、查询缓存或日志。

本地保存、后台路由注册、执行核对、真实能力校验分别显示。PENDING_SYNC/SYNCING为处理中，UNCERTAIN为待确认，SYNCED只证明平台执行配置已核对；能力UNKNOWN时禁止设默认和创建。新增模型或更换密钥后，后台同步完成即自动执行真实能力校验；关闭页面不影响执行。已启用且通过校验的当前模型均自动续检，不要求成为个人默认；失败且未被引用的模型保留手动重试。页面轮询显示“等待自动校验”“正在校验”“可用”或“校验失败”，失败显示安全原因及“重试校验”，执行中不提供重复校验按钮。保存表单说明可能产生少量模型用量；只读目录和后台路由核对不调用推理。

创建/应用模型的选项只含当前Owner可用版本。已有实例冻结原版本，显式应用才改变；已选项失效时阻止提交，不悄悄改成其他连接或默认模型。撤销先使本地授权失效，再跟踪后台执行密钥撤销，全部版本完成后才允许归档。

## 5 登录、会话和错误

SPA确认未登录或收到业务401后，清理受保护缓存并自动通过`/auth/login?return_to=...`进入登录页，不要求再点击一次登录。保留当前业务路径，登录成功返回原页；返回地址沿用BFF白名单，不传递查询参数或外部网址。身份服务故障保留重试入口，不触发登录循环。浏览器在Go原生登录页输入邮箱/密码，BFF处理授权码、PKCE和Cookie。会话Cookie为Secure/HttpOnly，前端不读取OIDC Token。所有更改请求携带服务端颁发CSRF标识，身份回调不接受任意跳转地址。

账号登录页由Go内嵌HTML、CSS和渐进增强JS提供，统一DSH Cloud品牌；桌面采用左侧平台介绍、右侧登录表单的分栏布局，窄屏收起介绍并使用单列表单；支持密码显示切换、大写锁定提示和提交中反馈，失败保留邮箱并清空密码，无JS仍可提交原生表单。CSP仅为登录HTML开放同源脚本；表单采用同源Origin验证，HTML Referrer-Policy为strict-origin以兼容Chrome/Edge，协议响应为no-store。Vite开发和preview代理`/auth/`、`/oidc/`、`/v1/`到Go API，生产HTTPS入口提供相同路径。

认证失败引导重新登录；403说明缺少功能权限，404不泄露其他Owner对象，409展示版本冲突并刷新，429保留现有输入并遵守Retry-After。上游Key、请求正文和完整错误体不展示；模型失败不伪造完成，不触发隐藏重试或重建工作卷。

## 6 视觉和响应式规范

### 6.1 技术选型

使用Ant Design组件和统一`src/app/theme.ts`令牌及语义反馈色，主要颜色为#2563eb，侧栏#111c30，背景#fafbff，本地Host Grotesk字体及系统中文字体。桌面240px侧栏，手机抽屉导航；查询、创建和操作保留清晰主次。只在失败或用户打开诊断时展示平台状态。

主要交互使用不少于44px目标，手机输入字体16px，文字与按钮满足4.5:1对比度。名称和邮箱长值可换行或Tooltip查看完整值，表格必要时横向滚动，不造成页面整体溢出。375/768/1024/1440px验证布局，支持键盘跳过导航、可见焦点、表单错误关联与减少动态效果。

模型提供商账号编辑采用抽屉，保存/取消固定可见；模型说明、诊断和技术信息按需展开。用户必须知道的计费确认、删除名称确认、Key留空语义、状态和错误原因就近显示。

## 用户资源配额管理

侧栏管理区提供独立“资源配额”入口（`/app/quotas`），与用户管理并列。配额页支持搜索、状态筛选和分页，仅加载当前页用户的配额，展示四项“已占用 / 上限”和配额来源。用户管理不再提供配额按钮。点击“调整配额”打开编辑弹窗，显示默认继承/单独分配、四项有效上限、占用进度和组织总上限。实例数量同时决定可运行数量，不展示单独的运行数量输入。编辑单位为个、vCPU、GiB，客户端转换为 millicores/bytes，禁止非安全整数、低于占用和高于组织上限。只读或归档目标不可保存，加载失败禁用保存，写入版本冲突后须重新读取并确认；CSRF、会话失效和错误反馈遵循现有客户端协议。

`resource-quotas-panel.tsx` 管理用户筛选、分页及额度表格，配额查询缓存与编辑弹窗共享，保存结果立即更新对应行。`user-quota-dialog.tsx` 持有独立目标用户查询和版本，`api/management.ts` 提供类型化读取/保存。桌面三列、手机单列，输入具备关联标签，单位及占用口径明确；配额表示共享池使用上限。浏览器模拟用例 `tests/user-quota.spec.ts` 覆盖原生单位转换、占用边界、陈旧版本、读取故障与只读保护，不修改真实用户数据。

## 模型提供商页面

提供商列表仅显示标题和操作，省略概述文案；沿用Ant Design与平台语义色，单一主按钮“添加账号”，提供搜索和刷新；每个提供商显示名称、官方名称/API根、模型数量及可用数量，模型默认收起。展开显示模型状态、工作空间使用数量、校验与账号默认模型操作。版本、队列、密文引用不放进主列表。删除使用明确的确认对话框，引用阻塞和服务错误在对话框内保留；提交后显示后台清理状态。成功提示4秒后自动消失，可手动关闭；连续操作会重新计时。清理进度继续通过账号行的“正在删除”状态显示，错误提示保留供处理。

`ModelProvidersPanel`、`ProviderAccountEditor` 和 `ProviderAccountsClient` 分别负责账号列表、编辑和请求。编辑抽屉直接显示配置字段，下方为“可用模型”，单个账号最多20个模型。新增内置提供商须先同步成功才能保存。先选提供商与地址/Key，再同步列表；模型采用搜索、复选框、选择当前列表、清空与仅已选过滤。同步不擅自取消已有选择。自定义支持无鉴权与手工ID，能力限制折叠。编辑保留已选模型、空Key表示保留保存值，移除项单独预览；被工作空间使用的移除项阻止保存并给出下一步。修改提供商/API根通过新增连接完成。表单在提交或同步中禁止关闭和切换，取消销毁草稿/Key；Key仅短暂位于受控输入和请求体，不进入Query缓存、浏览器存储或日志。

保存后刷新提供商列表、个人模型、目录、默认和配置缓存，工作台继续使用单模型运行接口。桌面采用对齐列表，手机换行和44px操作目标，低动态效果沿用全局设置。

自定义/本地服务在提供商下拉框与账号列表中统一显示“自定义”，仅保留一个入口。选中后通过“接口协议”选择OpenAI或Anthropic；协议用于选择适配器，创建后与账号服务地址一起固定。

角色详情与编辑使用API-043的名称和用途说明，按功能分组显示；“工作数据”单列永久释放本人存储，目录浏览、文件预览与下载在“查看本人工作空间与数据”说明中明确。编辑支持权限名称、编码、用途及分组搜索，展示每项权限的编码和依赖；搜索保留已选项，分组全选/清空只影响当前显示的可分配权限。缺依赖时禁止保存，可显式点击“补选依赖权限”补齐。未知权限在详情保留编码，旧响应缺说明时只展示名称；不因目录更新自动授予或勾选权限。

用户管理“更多”菜单中的“删除”仅向拥有 `users:manage` 的管理员展示；当前登录用户和密码重置待确认用户禁用该菜单项。确认弹窗要求输入完整用户名并说明资产处理要求，提交使用DELETE和预期版本。成功关闭弹窗、反馈已撤销登录并刷新用户及配额缓存；失败保留目标和错误，版本冲突可重新读取。默认筛选“未删除用户”，可切换“已删除”查询归档历史，历史行仅保留角色改派，以便解除自定义角色的在用关系。删除是保留审计和不可变身份的软删除。

## 创建时选择资源与模型配置

工作空间创建抽屉提供工作空间名称、CPU、内存、存储和模型提供商账号。名称可选，留空自动生成；填写时使用1–32个字符，支持中文、字母、数字、下划线和短横线，校验错误在输入框下方显示。名称与资源、提供商绑定进入同一幂等提交，结果未知时不得编辑。CPU 可选1/2/4/8/16核，内存可选2/4/8/16/32/64 GiB，存储可选已批准容量，初始使用平台默认容量（初始 10 GiB），组合取自批准模板规格目录，初始使用组织默认资源。用户只选择模型提供商账号，后台自动以该账号默认模型初始化；抽屉不展示或选择具体模型。进入DSH后可切换该账号全部已启用、已同步且校验有效的模型，展示上游模型名称。相同提供商有多个账号时，选项追加账号名称区分。未选择账号时执行只读资源预检以展示可用额度，但禁止创建提交；账号无默认模型、默认模型失效、被移除或账号加载失败时禁止提交，不回退组织默认或其他账号。预检和创建同时绑定默认模型当前ID/版本与所选spec_id；默认或版本变化时重新预检。模型须启用、已同步、网关核对和能力校验有效。创建已接受的工作空间冻结模型版本，后续更改账号默认不更换已有实例。抽屉桌面宽760px、手机不超过视口；基础配置和扩展在桌面双列，手机单列，资源桌面三列、手机两列。底部固定显示模型、资源和扩展数量摘要以及取消、创建按钮。取消不提交，再次打开恢复默认资源并清空账号；提交中禁止关闭和重复提交，成功后进入详情。结果未知时隐藏编辑控件，仅重放原始幂等请求。资源目录加载失败可重试，不能提交失效的显式规格；容量或额度不足时允许调整规格并重新检查。

分页统一用于实例、用户、角色、资源配额和操作日志表格，默认每页10条，可选20、50条：显示“共N条 · 本页M条”及“第X / Y页”，提供首页、上一页、下一页和尾页。请求携带page与limit，直接查询目标页；筛选变化或每页数量变化回到第一页。总数缩减导致当前页越界时，自动重新读取新的末页；空结果显示第1/1页。加载中禁止切页，失败仍可回首页重试；手机端使用带可访问名称的44px图标按钮，页数和总条数保持可见。服务端统计仅含当前用户可访问且匹配筛选的记录。

## 工作空间列表与平台配置边界

工作空间沿用模型提供商页面的标题、主操作和分隔列表布局。顶部仅保留“工作空间实例”和创建按钮，下方集中状态筛选、名称前缀搜索与刷新。每行展示名称、真实状态、CPU/内存/存储、模型提供商名称和冻结模型，并提供详情入口；模型信息以“提供商 · 模型”展示，提供商名称缺失时仅展示模型，不推测厂商；运行中但未就绪明确显示“健康待确认”。桌面和手机使用同一列表，长名称与模型可换行，避免整页水平滚动。空结果、请求失败和重试分别反馈，分页保持原服务端授权与筛选范围。工作空间列表不展示“创建配置”摘要，资源和模型选择仅在创建抽屉内展示。

平台配置不提供模型连接、模型目录或默认模型编辑入口，也不读取模型配置/目录接口；展示运行资源、默认实例上限、保留期限；具备 defaults:write 时提供“初始化配置”或“修改配置”，按需展开运行检查。模型账号、允许模型和账号默认模型统一从“模型提供商”管理。平台页隐藏模型和模型适配器检查项，但总创建条件仍使用后端完整预检结果；创建抽屉按真实模型与资源结果决定是否可提交。已有组织模型和默认解析接口保留服务端能力，页面移除不迁移或删除现有数据。

## 模型提供商账号默认模型与操作日志查询

模型提供商账号新增/编辑中为已选模型指定一个默认模型，首次选中时自动取首项，删除当前默认后取首个保留模型；保存时明确提交default_model。展开账号可查看默认标记或将另一个可用模型设为默认，不影响其他账号。

操作日志列表显示时间、中文操作、变更摘要、操作者、对象名称和结果；详情抽屉展示配额原值/新值、状态、角色和权限变更，关联编号按需展开并可复制。支持最近24小时/7天/30天、操作、结果、对象编号筛选及分页，切换筛选回首页；桌面和手机仅表格内部横向滚动。历史未记录内容明确说明，不补造。系统事件显示系统，名称缺失时显示资源类型和编号。前端不接收密钥、密文及原始报告。

操作日志代码统一使用 `OperationLog` 命名：页面与格式化逻辑分别位于`src/features/operation-logs/operation-logs-panel.tsx`和`operation-log-format.ts`，客户端查询为 `ResourcesClient.operationLogs()`，后端查询为 `QueryService.OperationLogs()`，OpenAPI 使用 `OperationLog` / `OperationLogDetails` / `OperationLogList`。样式前缀及查询缓存分别使用 `operation-log-` 和 `operation-logs`。为兼容现有链接、调用、授权和分页游标，保留 `/app/audit`、`/v1/audit-events`、`audit:read` / `audit:organization` 及游标资源标识；数据库仍使用 `audit_events`。

模型提供商账号最多20个，列表使用统一分页控件，默认每页10条，可选20/50条；搜索覆盖全部账号，搜索和每页条数变化回到首页，后台删除导致页数减少时回退有效页，后台轮询保留当前页。配额保存、用户操作及提供商成功反馈统一4秒后自动消失，可手动关闭；待确认警告持续展示。相同成功提示再次触发时重新计时，组件卸载清理计时器。

模型厂商按稳定提供商 ID 匹配品牌 Logo，覆盖 OpenAI、Anthropic、Google Gemini、通义千问、DeepSeek、Moonshot AI 和 Z.AI。账号列表、添加/编辑账号、创建工作空间的提供商选择器统一使用 `ProviderLogo` / `ProviderLabel`；手机端保留 Logo。SVG 随前端本地部署，自定义及未知提供商使用通用图标。图片保持原始比例，名称独立显示，装饰图片不重复朗读。

工作空间与模型提供商共用 `ListSearch`：统一左侧搜索图标、清空按钮、刷新按钮及间距；桌面搜索操作区宽360px，手机端撑满可用宽度，控件至少44px高。工作空间输入停止250ms后按名称前缀查询，Enter立即查询，清空恢复当前状态筛选下的列表；提供商在本地即时筛选名称及模型。搜索条件变化回到首页。

工作空间列表成功加载且未应用筛选时，若暂无工作空间，在空状态说明下显示“创建第一个实例”按钮，使用与模型提供商“添加第一个账号”一致的默认描边按钮样式，复用工作空间创建抽屉和原有权限、资源、模型及幂等逻辑；加载中、请求失败、筛选无匹配或缺少创建/启动权限时不展示该按钮。

## 实例详情布局

点击“进入工作空间”先尝试直接交接；仅工作空间站点的连接失败或超时触发顶层连接恢复。站点连通后自动返回控制台重新鉴权，并在同一窗口进入，无需再次点击。续接意图只保存在该窗口的会话存储，绑定用户、实例和控制台来源，2分钟内有效且使用一次即清除；不包含票据或凭据。直接访问返回链接不会自动授权，恢复失败显示错误，不循环跳转。浏览器网络错误无法区分证书、DNS或CORS原因，页面不推断为证书问题。

详情页沿用工作空间的分隔布局和统一令牌：顶部返回、刷新，随后为实例名称、实际状态和主要操作，进入工作空间为主按钮。资源区展示CPU、内存、存储；模型区展示提供商与冻结版本的真实模型名。内部路由、配置版本、实例编号、创建/更新时间和保留信息收于“实例信息”；健康维度收于“运行检查”。运行与失败操作展示中文动作、状态、真实阶段和安全错误，失败重试复用原权限与幂等链路；不生成估算进度。详情和列表均优先使用后端model_display_name，路由别名缺少展示名称时显示“模型信息暂不可用”，不回退展示内部别名。375px下主操作占满一行、其他操作换行，资源三列、模型单列；长名称与诊断标识可换行。

实例详情的“更新模型提供商”弹窗只选择当前用户的有效模型提供商账号，使用该账号当前默认模型的精确ID/版本提交。选项仅包含默认模型已启用、已同步且校验有效的账号，不读取或展示组织模型。未选择、缺少读取权限、账号加载失败或所选默认模型失效时禁止提交，不回退其他配置。运行中应用新提供商会受控重启并保留工作盘；结果未知时仍按原幂等提交确认。

## 默认用户资源配置编辑

编辑采用 560px 抽屉，手机不超过视口。打开时读取批准模板/规格，运行模板由后台选取且不显示；仅允许目录内 CPU/内存组合，存储为带 GiB 标签的数字输入，范围 1–100 的整数，初始 10；输入容量须匹配同一 CPU/内存的批准 spec_id；空值、小数、越界或未批准组合禁止保存并在字段附近显示错误。每用户默认实例上限及数据保留期限按需求范围校验。没有批准项或加载失败时禁止保存，支持重新加载。运行配置不请求模型接口、不要求组织模型，账号默认模型仍由模型提供商管理。

打开时冻结配置版本；初始化使用 0，修改使用打开时版本。提交期间禁止关闭或重复提交；取消不写入，再次打开恢复最新值。版本冲突显示重新读取入口，读取后须再次确认保存。401 清理旧会话并返回登录。成功关闭抽屉并更新配置及用户配额缓存，成功提示 4 秒消失；错误持续保留供处理。

## 创建资源不足提示

打开创建抽屉即执行只读资源预检，在CPU、内存和存储选择框的标签旁显示“剩余 N 单位”，实例剩余数量显示在运行资源标题旁；所选值超出剩余额度时在对应字段旁标注“不足”，不另展示额度表格或计量说明；未选择账号不能创建。选择账号后，预检绑定其默认模型，即使模型仍在校验，也检查所选规格的容量与额度；创建提交继续要求模型同步、网关核对和校验均有效。预检发现额度或CPU/内存容量不足时优先显示具体资源提示和重新检查入口，不能被通用模型提示或其他检查顺序遮住。额度不足建议降低规格或联系管理员调整配额；空闲计算不足建议停止不再使用的工作空间后重查或联系管理员扩容。资源恢复后若模型仍不可用，恢复显示模型校验提示并禁止提交。可用量取个人和组织剩余承诺额度的较小值并截断到零，包含保留存储；创建并发名额耗尽单独提示。加载失败隐藏旧额度，未知或未初始化不显示为零，提交仍重新校验。

## 工作空间存储数据管理

REQ-19的入口为用户功能区“工作数据”及 `/app/storage`，展示本人活动、停止和保留资产；列表/详情包含原工作空间、已分配容量、实际数据用量及采集时间、资产/保留状态和安全备份摘要。可切换浏览 `/data/workspace` 与 `/data/dsh`，逐级进入目录；支持运行、停止或软删除的可用数据盘。普通文件支持不超过512 KiB的文本预览和不超过64 MiB的下载，符号链接及其他特殊文件不能打开。文件名、类型、大小和更新时间清楚呈现；加载、空目录和失败分别反馈。页面无上传、编辑或文件删除入口。资产编号、删除时间及维护条件折叠展示，空备份不显示分页；备份与恢复提供管理员指引。具备 `instances:release-storage` 的Owner可点击“释放存储”，输入工作空间名称后二次确认，允许提前释放已删除工作空间的保留数据；法律保留和任务冲突禁用入口。提交后显示释放待确认，物理回收完成后返还额度。细则与验收见[REQ-19](requirements.md#612-工作空间存储数据管理req-19)。页面调用API-077～082；会话失效清除缓存，查询失败隐藏旧详情。

已回收资产在列表中为具有 `instances:release-storage` 的本人显示删除图标；弹窗显示名称和资产编号，确认后从列表移除，保留备份及后台记录。取消不提交，失败显示错误并保留记录。该操作不同于“释放存储”，不会发起物理回收。

实例详情的扩展配置、运行检查与实例信息均为折叠区。扩展配置只显示有内容的类别，技能使用创建快照，其余类别显示版本、范围和状态；空、失权及读取失败分别反馈。运行检查显示各项状态与异常原因，不展示健康数量汇总。

## 进入工作空间的过渡状态

新窗口立即展示轻量的居中连接页：DSH Cloud、工作空间名称、柔和加载图标及“正在为你连接，准备好后会自动进入”。连接恢复页和返回控制台后的鉴权等待保持相同视觉，避免闪回详情；不增加最短等待时间或虚假进度。减少动画设置下禁用旋转；小屏保持文本换行与至少44px的返回入口。初始窗口失败后保留错误及“返回实例详情重试”，原控制台同步反馈；用户主动返回后不再强制跳入工作空间。名称和安全错误作为纯文本插入，票据继续只通过隐藏POST字段提交。Gateway公开连接页仅允许固定样式哈希，脚本及表单仍禁止，自动续接与鉴权边界保持原规则。

## 工作空间插件与 Agent 预设

## 个人技能包

技能包页面使用一个“导入”按钮，打开同一弹窗的“搜索技能 / 链接导入 / 文件导入”页签，默认显示搜索。搜索支持 skills.sh、ClawHub、SkillHub 和 SkillsMP，输入 2–100 个字符后查询公开技能，展示名称、作者、安装量、下载量或 GitHub 星标数以及来源链接；结果缓存 60 秒。选择“预览并导入”复用现有差异预览和确认流程，搜索本身不保存技能。来源错误和空结果提供重试或切换提示。skills.sh 按技能名称从 GitHub 仓库中筛选单个技能并保留资源文件；ClawHub 使用作者和技能标识下载公开 ZIP，受限或需要 GitHub 转交的条目显示来源提示。SkillHub 优先展示中文描述，来源详情链接按官方插件使用 `https://skillhub.cn/skills/{slug}` 路由（兼容旧 `api.skillhub.cn/{owner}/{slug}` 及 `skillhub.cn/{owner}/{slug}` 链接，避免 405 或站内未找到页面），通过官方 API 下载 ZIP，并仅允许跳转到腾讯 COS 的 HTTPS ZIP 地址；临时下载地址不持久保存。SkillsMP 保留市场详情链接，使用其提供的 GitHub 目录或文件链接进入预览，热度标为星标。SkillsMP 匿名搜索受来源配额限制，错误时可重试或切换来源。

工作台 `/app/skills` 由 `features/skills/skills-panel.tsx` 与 `api/skills.ts` 提供，入口按 `skills:read` 显示，编辑/导入/同步按 `skills:manage` 显示。沿用 Ant Design、统一分页和搜索；桌面按行列出，手机自适应排列来源和操作；页面不提供自动调用、手动调用设置，导入预览和编辑说明也不展示相关提示。

创建工作空间抽屉增加可选“选择技能”，按 `skills:read` 显示，从完整分页个人技能列表提供搜索、多选和清空。提交只包含 ID 与版本，待确认请求重放同一选择，不将正文、描述或附属文件写入浏览器提交记录。技能列表失败可重试，不选技能仍可继续；已选技能版本变化或失效时需清空并重新选择。所选技能创建时复制并在该工作空间启用，页面直接说明该行为。

编辑抽屉可选择 `SKILL.md` 或包内其他已有文件；“新建文件”可填写相对路径（如 `scripts/run.py`）与内容，保存成功后刷新文件列表并打开新文件。创建失败保留输入，版本冲突可刷新版本；关闭新建弹窗前保护已输入内容。UTF-8 文本支持编辑和保存，二进制文件显示下载提示；只读用户只能查看。文件读取返回整个技能包版本，保存使用该版本避免覆盖并发更新。切换文件、关闭和重新读取均保护未保存内容；加载失败、保存失败和冲突保留当前编辑。后台刷新不覆盖未保存输入。导入与来源更新先预览差异，再确认跳过或保留上一版后替换。仅关联外部链接的技能显示“来源与同步”；手动创建和文件上传的技能隐藏此栏。导出前展示文件清单。个人技能库内容加密存于平台数据库，不通过浏览器本地存储持久化；仅创建时明确选中的技能副本进入工作空间，不新增 DSH 页面或插件。


## 外接记忆与知识库

`/app/memory` 与 `/app/knowledge` 复用现有Ant Design布局；菜单分别要求 `memory:read`、`knowledge:read`，管理另外要求对应 `:manage`。支持连接验证、预览后保存、内容维护、迁移包、UTF-8文档导入、工作数据显式选择、试检索和授权原文查看。页面在工作台内提供操作，工作空间关联只保存关系，不加载到DSH。内置管理员和成员默认拥有本人内容权限，自定义角色按需授权。所有查询按用户、连接版本和范围隔离，失效登录清空缓存。详见[实施记录](context-implementation.md)。


“添加记忆连接”与“添加知识库连接”使用 `context-service-picker.tsx`：先搜索并选择方案，再填写相应服务、连接名称和凭据；默认名称及唯一服务自动填入。桌面三列、手机单列，支持返回选择；未配置方案显示简短提示，保存失败保留输入；打开配置后聚焦名称，必填校验自动滚动并聚焦首个错误字段。保存期间锁定表单，启用开关与连接器布局一致；低高度横屏保持操作按钮完整可见。内容录入表单统一标签、占位提示及滚动区域，发送外部服务仍须预览确认。

## 工作台连接器（MCP）

工作台 `/app/connectors` 使用 `features/connectors` 和 `api/connectors.ts`，与技能包、记忆、知识库并列。读取权限显示入口，管理和调用权限分别控制配置/工具开关及试调用。列表统一搜索分页，主操作区仅保留“添加连接器”，不提供配置导入导出入口；详情分工具、连接信息、调用记录，支持桌面与手机。参数先预览再确认，行为未知或有副作用额外确认；未知结果不自动重试。结果作为纯文本JSON展示，调用正文不持久保存。 细节见[实施记录](connectors-implementation.md)。

“添加连接器”先打开 `connector-catalog.tsx` 的内置目录抽屉，支持38种服务的搜索与8类数量筛选，桌面三列、手机单列，整块服务可点击，展示“官方默认地址/OAuth授权/需部署网关”等接入状态。每个目录连接器与右上角“自定义 MCP”均可填写本人的 HTTPS MCP 地址及认证信息，无需管理员预先绑定公网服务。目录服务预填名称、说明；19种官方服务预填地址和相应认证方式，即使平台未配置推荐列表也可从目录元数据预填，其余服务在地址字段说明如何部署或获取地址。推荐地址可选择填入并自行修改。乐享提供企业标识及令牌字段，二者加密保存且不读回。新建、编辑和复制统一提交个人 `url` 与可选 `catalog_id`，平台旧连接编辑时同样开放地址。接入准备按需展开，CLI、stdio及旧SSE服务须先部署兼容网关。协议及说明收进“更多设置”。支持“返回选择”，编辑/复制恢复目录说明，凭据不读回；原地址编辑可留空保留Bearer凭据，更换地址或复制须重新填写。搜索和分类固定在顶部，服务区域独立滚动，适配键盘与减少动效设置。

OAuth连接使用“授权连接／重新授权”，内置5个远程服务预填推荐地址，支持自行修改；自定义MCP可选择OAuth认证。授权起始失败保留输入，重试更新原连接；官方授权返回后展示结果并清理提示参数，工具需自行选择启用。停用连接只保存配置，不发起授权。

企查查当前使用通用OAuth/Bearer配置与企业信息MCP地址。单卡片专用双模式、五类服务状态及远端解绑界面属于[第6.17.2节待交付需求](requirements.md#6172-企查查完整接入扩展交付)，不能按已实现页面描述。

## 创建工作空间扩展（REQ-25）

创建抽屉保留技能选择，另用`CreateExtensions`提供连接器、记忆、知识库、插件四组搜索多选与清空，展示匹配图标、已选数量和冻结版本；记忆/知识库可选个人及本工作空间范围。候选仅查询本人完整列表，权限不足不请求对应数据；各组独立加载重试，空选组故障不阻止基础创建，已选失效版本必须明确去选后重选。五类分组各保留一层选择标题，创建抽屉不提供管理跳转；图标与冻结版本直接显示在已选标签中，避免重复清单。基础配置、运行资源和扩展能力分区展示，取消后重新打开清空未提交的选择；结果待确认时继续复用原请求。兼容插件白名单由API返回，禁选项说明版本或依赖原因。

同一创建幂等请求保存全部ID、版本和范围，不存密钥或正文；结果未知继续确认原请求。详情`WorkspaceExtensionStatus`每5秒获取当前逐项状态，区分运行中、扩展可用、停止、失败与重新授权，并提供失败指引。375px与桌面共用同一表单，长包名换行，底部操作固定可达。
