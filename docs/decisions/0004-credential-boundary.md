# ADR-04 平台与模型凭据边界

- 版本：V0.1
- 范围：单组织 Docker 初始版本
- 状态：已选择设计，待实现验证
- 负责人职责：后端/集成开发与安全验证
- 关联需求：REQ-03、REQ-06、REQ-07、REQ-11、REQ-12

## 1 合理性评估

合理。存储加密、运行时可见性和有效撤销是不同保证，必须分别说明。

## 2 背景与约束

平台处理管理凭据、模型 Key 和原生交接秘密。用户工作空间可以执行文件工具及 Shell，不能把业务上的 Owner 隔离等同于用户读不到注入的 Key。

## 3 备选方案

| 方案 | 收益 | 代价与结论 |
| --- | --- | --- |
| 受控保存后注入指定 DSH 组件 | 实现直接 | Shell 可能读取，仅适合已接受边界的内部试点 |
| 已验证模型凭据代理 | 可集中限制/撤销调用 | 增加协议与工具兼容验证，需隐藏 Key 时采用 |
| 明文配置入库或返回浏览器 | 简单 | 不满足安全要求，不采用 |

## 4 当前选择

管理员专用接口写入模型凭据，业务记录保存引用和版本，响应只返回脱敏元数据。首版固定Go AES-256-GCM密文存PostgreSQL、随机nonce/AAD/key_id、外置32-byte主密钥只读文件，主密钥独立于数据库及其备份。具体结构见 [安全设计](../security.md#5-密钥与加密)。

平台/OIDC/数据库/控制面管理秘密不进入用户容器。模型 Key 仅供批准用途；直接注入时明确 Shell 可读取风险，需要隐藏时采用已验证代理。

配置保存生成版本，实例显式应用。撤销立即禁止平台新使用并处理受影响实例；已复制 Key 的失效依赖上游吊销。一个组织共享 Key 的吊销会影响其他实例，不承诺单实例吊销共享 Key。

## 5 代价与边界

配置回滚不能恢复已撤销秘密。主机、数据库和密钥系统的特权运维属于受信边界，平台不能承诺抵抗持有这些权限的人员；访问需最小权限及审计。自动轮换不属于初始版本。

## 6 验证与放行

TC-10、TC-19、TC-23、TC-28、TC-29。检查无明文读回/日志/镜像秘密，验证密文恢复、主密钥管理、配置冲突、共享 Key 吊销影响和上游失效。

用例定义见 [测试验收](../testing.md)，结果当前未执行。验证失败时暂停对应能力放行，重新评审方案。
